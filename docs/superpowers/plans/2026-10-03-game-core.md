# Laddorious Spec #1 — Game Core, Board Generator & Simulator — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the deterministic Laddorious rules engine (`@laddorious/core`), its seeded board generator with Markov validation, and a headless bot simulator with a CLI (`@laddorious/sim`).

**Architecture:** A pnpm TypeScript monorepo. `core` is a pure state machine: `step(state, input) → { state, events }` over plain-JSON state, with every random number drawn from seeded sfc32 streams stored in that state, so a match replays exactly from `(config, seats, inputs)`. The host (the simulator now, a server later) owns the clock and sends `timeout` inputs. `sim` drives matches with bots that only see `viewFor(state, player)`, and reports length, fairness and card metrics.

**Tech Stack:** Node ≥ 24, pnpm 11, TypeScript `~6.0.3`, Vitest 5, fast-check 4, tsx 4, ESLint 10 + typescript-eslint 8.

**Spec:** `docs/superpowers/specs/2026-10-03-game-core-design.md` (decisions D1–D21). Read it alongside this plan.

## Global Constraints

- Node `>=24`; `"packageManager": "pnpm@11.5.0"`; all packages `"type": "module"`, `"private": true`.
- TypeScript pinned to `~6.0.3` — **not 7.x**: typescript-eslint 8.71 supports TypeScript `<6.1.0` only.
- `@laddorious/core` has **zero runtime dependencies**. Its `package.json` exports `./src/index.ts` directly (no build step; Vitest and tsx run TS sources).
- No `Math.random`, `Date` or `performance` anywhere in `packages/core/src` (ESLint-enforced). All randomness goes through `RngStream`; probabilities are integer weights.
- `MatchState` is plain JSON. `step` never mutates its input state. Invalid input returns `{ ok: false, error }`; only bugs throw.
- 2–4 players; player ids match `/^[A-Za-z0-9_-]{1,32}$/` and are not `Object.prototype` names.
- Board: 100 tiles; tile 0 is the off-board safe start; tile N is the final tile.
- Defaults (spec §9): windows dice 12 000 ms / bonus grace 5 000 / challenge 8 000 / Mystery 15 000; knockback 3; maxReplays 3 (≤ 4 pick rounds); maxWaves 3; maxRerolls 2; Mystery density 0.18; rarity weights Common 70 / Rare 25 / Epic 5; ladders and snakes 8–10 each, length 4–30.
- Work on a feature branch; commit at the end of every task.

## Review Focus

Inputs the spec implies but its examples never exercise, most likely to bite first. Each one is pinned by a test in the owning task:

1. **A host retries a `timeout` for a window that already closed** (network retry) → must return `STALE_TIMEOUT`, never apply twice. — Task 9, `step.test.ts`.
2. **The state is persisted as JSON mid-match and resumed** (server restart; number-keyed records become string-keyed) → the continuation must be identical. — Task 9, `step.test.ts`.
3. **Player ids such as `constructor` or `__proto__`** → `createMatch` must throw `ConfigError` instead of silently corrupting per-player records. — Task 9, `create.test.ts`.
4. **A card's board edit that would close a loop with existing jumps** (a ladder top landing on a snake head that leads back to the ladder foot) → the placement must skip that tile or fizzle; a cycle would hang the settle loop. — Task 8, `boardEdit.test.ts`.
5. **A daily-challenge seed reused with a different player count** → must produce the same board. — Task 9, `create.test.ts`.

## Clarifications made while planning

Small decisions the spec leaves open or states loosely, implemented as follows (reviewers: these are intentional):

- Mystery rarity weights live in `BoardConfig.mysteryRarityWeights` (rarity is assigned at generation, so "same seed → same board" includes rarity). Spec §9 lists them under `mystery`.
- Spec §5.5's `untilTriggered` lifetime is expressed as `charges: 1` (an `afterMove` effect spends a charge each time it is evaluated). The `conditional` op carries a movement `amount` — the only payload the starter set needs.
- `Moved` events carry `bounced: boolean` instead of a separate `bounce` cause. `ChallengeStarted.theme` is `null` for RPS.
- Hidden targets are locked when the selections are revealed. Nothing moves during selection, so this is equivalent to locking at pick time.
- If every contestant times out in a later pick round, the random winner is drawn from that round's contestants. In round 1 these are the original participants, as the spec says.
- Within one simultaneous group, shields absorb attacks in caster seat order.
- An effect with `rounds: n` created in round r expires at the end of round r + n (spec §5.5: "through the next n full rounds").

```ts
/** cyrb128 string hash → four unsigned 32-bit words. Used to seed PRNG streams and to hash states. */
export function cyrb128(str: string): [number, number, number, number] {
  let h1 = 1779033703;
  let h2 = 3144134277;
  let h3 = 1013904242;
  let h4 = 2773480762;
  for (let i = 0; i < str.length; i++) {
    const k = str.charCodeAt(i);
    h1 = h2 ^ Math.imul(h1 ^ k, 597399067);
    h2 = h3 ^ Math.imul(h2 ^ k, 2869860233);
    h3 = h4 ^ Math.imul(h3 ^ k, 951274213);
    h4 = h1 ^ Math.imul(h4 ^ k, 2716044179);
  }
  h1 = Math.imul(h3 ^ (h1 >>> 18), 597399067);
  h2 = Math.imul(h4 ^ (h2 >>> 22), 2869860233);
  h3 = Math.imul(h1 ^ (h3 >>> 17), 951274213);
  h4 = Math.imul(h2 ^ (h4 >>> 19), 2716044179);
  h1 ^= h2 ^ h3 ^ h4;
  h2 ^= h1;
  h3 ^= h1;
  h4 ^= h1;
  return [h1 >>> 0, h2 >>> 0, h3 >>> 0, h4 >>> 0];
}

/** 32 hex chars of cyrb128 — a stable fingerprint for strings. */
export function hashString(str: string): string {
  return cyrb128(str)
    .map((w) => w.toString(16).padStart(8, '0'))
    .join('');
}
```

`packages/core/src/rng/stream.ts`:
```ts
import { cyrb128 } from './hash';

/**
 * A PRNG stream stored as plain JSON data inside the match state.
 * Functions in this module mutate the stream object in place; callers
 * own a cloned draft of the state, so this stays pure from the outside.
 */
export type RngStream =
  | { kind: 'sfc32'; s: [number, number, number, number] }
  | { kind: 'scripted'; values: number[]; index: number };

export function createStream(label: string): RngStream {
  const s = cyrb128(label);
  const stream: RngStream = { kind: 'sfc32', s };
  // Discard the first outputs: sfc32 needs a few rounds to mix a hashed seed.
  for (let i = 0; i < 12; i++) nextU32(stream);
  return stream;
}

/** Test-only stream: each nextInt() call returns the next scripted value. */
export function scriptedStream(values: number[]): RngStream {
  return { kind: 'scripted', values: [...values], index: 0 };
}

export function nextU32(stream: RngStream): number {
  if (stream.kind === 'scripted') {
    throw new Error('nextU32 is not available on scripted streams; use nextInt');
  }
  const st = stream.s;
  let a = st[0] | 0;
  let b = st[1] | 0;
  let c = st[2] | 0;
  let d = st[3] | 0;
  const t = (((a + b) | 0) + d) | 0;
  d = (d + 1) | 0;
  a = b ^ (b >>> 9);
  b = (c + (c << 3)) | 0;
  c = (c << 21) | (c >>> 11);
  c = (c + t) | 0;
  st[0] = a >>> 0;
  st[1] = b >>> 0;
  st[2] = c >>> 0;
  st[3] = d >>> 0;
  return t >>> 0;
}

/** Uniform integer in [0, n). Rejection sampling avoids modulo bias. */
export function nextInt(stream: RngStream, n: number): number {
  if (!Number.isInteger(n) || n <= 0 || n > 0x100000000) {
    throw new RangeError(`nextInt: n must be an integer in 1..2^32, got ${n}`);
  }
  if (stream.kind === 'scripted') {
    const v = stream.values[stream.index];
    if (v === undefined) throw new Error('scripted stream exhausted');
    if (!Number.isInteger(v) || v < 0 || v >= n) {
      throw new RangeError(`scripted value ${v} out of range for nextInt(${n})`);
    }
    stream.index++;
    return v;
  }
  const limit = 0x100000000 - (0x100000000 % n);
  for (;;) {
    const x = nextU32(stream);
    if (x < limit) return x % n;
  }
}

/** Uniform integer in [min, max] inclusive. */
export function intBetween(stream: RngStream, min: number, max: number): number {
  if (max < min) throw new RangeError(`intBetween: max ${max} < min ${min}`);
  return min + nextInt(stream, max - min + 1);
}

export function rollDie(stream: RngStream): number {
  return nextInt(stream, 6) + 1;
}

/** Index chosen with probability weights[i] / sum(weights). Weights are non-negative integers. */
export function pickWeighted(stream: RngStream, weights: readonly number[]): number {
  let total = 0;
  for (const w of weights) {
    if (!Number.isInteger(w) || w < 0) throw new RangeError(`weights must be non-negative integers, got ${w}`);
    total += w;
  }
  if (total <= 0) throw new RangeError('pickWeighted: weights sum to 0');
  let r = nextInt(stream, total);
  for (let i = 0; i < weights.length; i++) {
    r -= weights[i]!;
    if (r < 0) return i;
  }
  throw new Error('unreachable');
}

export function pickOne<T>(stream: RngStream, items: readonly T[]): T {
  if (items.length === 0) throw new RangeError('pickOne: empty list');
  return items[nextInt(stream, items.length)]!;
}
```

```ts
export const RARITIES: readonly Rarity[] = ['common', 'rare', 'epic'];

export type JumpKind = 'snake' | 'ladder';

/** A snake (to < from) or ladder (to > from). */
export interface Jump {
  id: string;
  from: number;
  to: number;
}

export interface Board {
  /** N — the final tile. Tile 0 is the off-board start. */
  size: number;
  jumps: Jump[];
  /** tile → rarity; keys are tiles in 1..N-1 */
  mystery: Record<number, Rarity>;
  seed: string;
  generatorVersion: number;
}

export function jumpKind(j: Jump): JumpKind {
  return j.to < j.from ? 'snake' : 'ladder';
}

export function jumpLength(j: Jump): number {
  return Math.abs(j.to - j.from);
}

export function jumpFrom(board: Board, tile: number): Jump | undefined {
  return board.jumps.find((j) => j.from === tile);
}

export function isSnakeHead(board: Board, tile: number): boolean {
  const j = jumpFrom(board, tile);
  return j !== undefined && j.to < j.from;
}
```

```ts
import type { Board } from './types';

/**
 * Hard board invariants (spec §5.7). They hold for generated boards and
 * after every card edit. Returns human-readable violations; empty = valid.
 */
export function boardViolations(board: Board): string[] {
  const out: string[] = [];
  const N = board.size;
  const starts = new Set<number>();

  for (const j of board.jumps) {
    if (j.from === j.to) out.push(`${j.id}: from equals to (${j.from})`);
    if (j.from < 1 || j.from > N - 1) out.push(`${j.id}: from ${j.from} outside 1..${N - 1}`);
    if (j.to < 1 || j.to > N - 1) out.push(`${j.id}: to ${j.to} outside 1..${N - 1}`);
    if (starts.has(j.from)) out.push(`${j.id}: second jump starting on tile ${j.from}`);
    starts.add(j.from);
    if (board.mystery[j.from] !== undefined) out.push(`${j.id}: starts on Mystery tile ${j.from}`);
  }

  for (const key of Object.keys(board.mystery)) {
    const tile = Number(key);
    if (!Number.isInteger(tile) || tile < 1 || tile > N - 1) out.push(`mystery tile ${key} outside 1..${N - 1}`);
  }

  // Acyclic: following jumps from any start must terminate.
  const next = new Map(board.jumps.map((j) => [j.from, j.to] as const));
  for (const j of board.jumps) {
    const seen = new Set<number>([j.from]);
    let tile = j.to;
    while (next.has(tile)) {
      if (seen.has(tile)) {
        out.push(`cycle through tile ${tile}`);
        break;
      }
      seen.add(tile);
      tile = next.get(tile)!;
    }
  }
  return [...new Set(out)];
}
```

```ts
import type { Board } from './types';

export interface BoardAnalysis {
  /** cdf[r] = P(a single player, dice only, has finished by the end of round r). cdf[0] = 0. */
  cdf: number[];
  /** Median round in which the first of n independent players finishes (Infinity if never within maxRounds). */
  medianFirstFinish: { 2: number; 3: number; 4: number };
  /** P(first finish happens after round r) for n players. */
  tailAfter(n: number, r: number): number;
}

/**
 * One round of dice-only movement (spec §7.3): a 6 always takes the bonus
 * roll, so totals 1..5 have p=1/6 and totals 7..12 have p=1/36.
 */
const ROUND_TOTALS: ReadonlyArray<readonly [total: number, p: number]> = [
  [1, 1 / 6], [2, 1 / 6], [3, 1 / 6], [4, 1 / 6], [5, 1 / 6],
  [7, 1 / 36], [8, 1 / 36], [9, 1 / 36], [10, 1 / 36], [11, 1 / 36], [12, 1 / 36],
];

/** Destination tile after moving `total` from `from` with bounce and jump chains. */
export function landingTile(board: Board, from: number, total: number, next = jumpMap(board)): number {
  const N = board.size;
  let to = from + total;
  if (to > N) to = N - (to - N);
  if (to < 0) to = 0;
  let guard = 0;
  while (next.has(to)) {
    to = next.get(to)!;
    if (++guard > board.jumps.length) throw new Error('jump cycle in analysis');
  }
  return to;
}

function jumpMap(board: Board): Map<number, number> {
  return new Map(board.jumps.map((j) => [j.from, j.to] as const));
}

export function analyzeBoard(board: Board, maxRounds = 300): BoardAnalysis {
  const N = board.size;
  const next = jumpMap(board);
  // Precompute transitions per tile.
  const transitions: Array<Array<[number, number]>> = [];
  for (let p = 0; p < N; p++) {
    const row = new Map<number, number>();
    for (const [t, prob] of ROUND_TOTALS) {
      const q = landingTile(board, p, t, next);
      row.set(q, (row.get(q) ?? 0) + prob);
    }
    transitions.push([...row.entries()]);
  }

  let dist = new Float64Array(N + 1);
  dist[0] = 1;
  const cdf: number[] = [0];
  for (let r = 1; r <= maxRounds; r++) {
    const nextDist = new Float64Array(N + 1);
    nextDist[N] = dist[N]!;
    for (let p = 0; p < N; p++) {
      const mass = dist[p]!;
      if (mass === 0) continue;
      for (const [q, prob] of transitions[p]!) nextDist[q] = nextDist[q]! + mass * prob;
    }
    dist = nextDist;
    cdf.push(Math.min(1, dist[N]!));
  }

  const tailAfter = (n: number, r: number): number => {
    const f = cdf[Math.min(r, cdf.length - 1)]!;
    return Math.pow(1 - f, n);
  };
  const median = (n: number): number => {
    for (let r = 1; r < cdf.length; r++) if (1 - tailAfter(n, r) >= 0.5) return r;
    return Infinity;
  };
  return { cdf, medianFirstFinish: { 2: median(2), 3: median(3), 4: median(4) }, tailAfter };
}
```

```ts
import { createStream, intBetween, pickWeighted, type RngStream } from '../rng/stream';
import { analyzeBoard, type BoardAnalysis } from './analysis';
import type { BoardConfig } from './config';
import { boardViolations } from './invariants';
import { RARITIES, jumpKind, jumpLength, type Board, type Jump, type Rarity } from './types';

export type RejectionReason =
  | 'placement'
  | 'mystery-placement'
  | 'invariant'
  | 'chain'
  | 'length'
  | 'count'
  | 'finish-zone'
  | 'snake-run'
  | 'mystery-spacing'
  | 'analysis-median'
  | 'analysis-tail';

export interface GenerationReport {
  attempts: number;
  rejections: Partial<Record<RejectionReason, number>>;
  analysis: { median4p: number; median2p: number; tail2p: number };
}

export class GenerationError extends Error {
  constructor(
    readonly seed: string,
    readonly config: BoardConfig,
    readonly rejections: Partial<Record<RejectionReason, number>>,
  ) {
    super(`board generation failed for seed "${seed}" after ${config.maxAttempts} attempts: ${JSON.stringify(rejections)}`);
    this.name = 'GenerationError';
  }
}

export function boardStreamLabel(seed: string, generatorVersion: number): string {
  return `${seed}|board|v${generatorVersion}`;
}

/** Spec §7.2. Deterministic in (seed, cfg). */
export function generateBoard(seed: string, cfg: BoardConfig): { board: Board; report: GenerationReport } {
  const rng = createStream(boardStreamLabel(seed, cfg.generatorVersion));
  const rejections: Partial<Record<RejectionReason, number>> = {};
  const reject = (r: RejectionReason) => {
    rejections[r] = (rejections[r] ?? 0) + 1;
  };

  for (let attempt = 1; attempt <= cfg.maxAttempts; attempt++) {
    const candidate = drawCandidate(seed, cfg, rng);
    if (typeof candidate === 'string') {
      reject(candidate);
      continue;
    }
    const structural = structuralViolations(candidate, cfg);
    if (structural.length > 0) {
      reject(structural[0]!);
      continue;
    }
    const analysis = analyzeBoard(candidate);
    const verdict = analyticVerdict(analysis, cfg);
    if (verdict !== null) {
      reject(verdict);
      continue;
    }
    return {
      board: candidate,
      report: {
        attempts: attempt,
        rejections,
        analysis: {
          median4p: analysis.medianFirstFinish[4],
          median2p: analysis.medianFirstFinish[2],
          tail2p: analysis.tailAfter(2, cfg.analysis.maxRounds2p),
        },
      },
    };
  }
  throw new GenerationError(seed, cfg, rejections);
}

export function analyticVerdict(analysis: BoardAnalysis, cfg: BoardConfig): RejectionReason | null {
  const [lo, hi] = cfg.analysis.median4pRounds;
  const m = analysis.medianFirstFinish[4];
  if (!(m >= lo && m <= hi)) return 'analysis-median';
  if (analysis.tailAfter(2, cfg.analysis.maxRounds2p) >= cfg.analysis.maxTailProbability) return 'analysis-tail';
  return null;
}

function drawCandidate(seed: string, cfg: BoardConfig, rng: RngStream): Board | RejectionReason {
  const N = cfg.size;
  const jumps: Jump[] = [];
  const starts = new Set<number>();
  const ends = new Set<number>();
  let finishZoneSnakes = 0;
  const zoneStart = N - cfg.finishZone.tiles;

  const kinds: Array<'snake' | 'ladder'> = [
    ...Array<'snake'>(intBetween(rng, cfg.snakes.count[0], cfg.snakes.count[1])).fill('snake'),
    ...Array<'ladder'>(intBetween(rng, cfg.ladders.count[0], cfg.ladders.count[1])).fill('ladder'),
  ];

  for (const kind of kinds) {
    const range = kind === 'snake' ? cfg.snakes.length : cfg.ladders.length;
    let placed = false;
    for (let tries = 0; tries < 50 && !placed; tries++) {
      const len = intBetween(rng, range[0], range[1]);
      let from: number;
      let to: number;
      if (kind === 'snake') {
        if (len + 1 > N - 1) continue;
        from = intBetween(rng, len + 1, N - 1);
        to = from - len;
      } else {
        if (N - 1 - len < 1) continue;
        from = intBetween(rng, 1, N - 1 - len);
        to = from + len;
      }
      if (starts.has(from) || ends.has(from) || starts.has(to)) continue; // one start per tile, no chains
      const inZone = kind === 'snake' && from >= zoneStart;
      if (inZone && (finishZoneSnakes >= cfg.finishZone.maxSnakes || len > cfg.finishZone.maxSnakeLength)) continue;
      if (kind === 'snake' && wouldExceedSnakeRun(jumps, from, cfg.maxConsecutiveSnakeHeads)) continue;
      jumps.push({ id: `j${jumps.length + 1}`, from, to });
      starts.add(from);
      ends.add(to);
      if (inZone) finishZoneSnakes++;
      placed = true;
    }
    if (!placed) return 'placement';
  }

  // Mystery tiles: stratified — one per equal segment of 1..N-1, never on a jump start.
  const mystery: Record<number, Rarity> = {};
  const count = Math.round(N * cfg.mysteryDensity);
  const rarityWeights = RARITIES.map((r) => cfg.mysteryRarityWeights[r]);
  for (let i = 0; i < count; i++) {
    const segStart = 1 + Math.floor((i * (N - 1)) / count);
    const segEnd = Math.floor(((i + 1) * (N - 1)) / count);
    const options: number[] = [];
    for (let t = segStart; t <= segEnd; t++) if (!starts.has(t)) options.push(t);
    if (options.length === 0) return 'mystery-placement';
    const tile = options[intBetween(rng, 0, options.length - 1)]!;
    mystery[tile] = RARITIES[pickWeighted(rng, rarityWeights)]!;
  }

  return { size: N, jumps, mystery, seed, generatorVersion: cfg.generatorVersion };
}

function wouldExceedSnakeRun(jumps: Jump[], from: number, maxRun: number): boolean {
  const heads = new Set(jumps.filter((j) => j.to < j.from).map((j) => j.from));
  heads.add(from);
  let run = 1;
  for (let t = from - 1; heads.has(t); t--) run++;
  for (let t = from + 1; heads.has(t); t++) run++;
  return run > maxRun;
}

/** Generator-only rules on top of the hard invariants (spec §7.2 step 2). First entry is the primary reason. */
export function structuralViolations(board: Board, cfg: BoardConfig): RejectionReason[] {
  const out: RejectionReason[] = [];
  const N = board.size;
  if (boardViolations(board).length > 0) out.push('invariant');

  const starts = new Set(board.jumps.map((j) => j.from));
  if (board.jumps.some((j) => starts.has(j.to))) out.push('chain');

  const snakes = board.jumps.filter((j) => jumpKind(j) === 'snake');
  const ladders = board.jumps.filter((j) => jumpKind(j) === 'ladder');
  const inRange = (v: number, [lo, hi]: [number, number]) => v >= lo && v <= hi;
  if (!inRange(snakes.length, cfg.snakes.count) || !inRange(ladders.length, cfg.ladders.count)) out.push('count');
  if (
    snakes.some((j) => !inRange(jumpLength(j), cfg.snakes.length)) ||
    ladders.some((j) => !inRange(jumpLength(j), cfg.ladders.length))
  ) {
    out.push('length');
  }

  const zoneSnakes = snakes.filter((j) => j.from >= N - cfg.finishZone.tiles);
  if (
    zoneSnakes.length > cfg.finishZone.maxSnakes ||
    zoneSnakes.some((j) => jumpLength(j) > cfg.finishZone.maxSnakeLength)
  ) {
    out.push('finish-zone');
  }

  const heads = new Set(snakes.map((j) => j.from));
  let run = 0;
  for (let t = 1; t < N; t++) {
    run = heads.has(t) ? run + 1 : 0;
    if (run > cfg.maxConsecutiveSnakeHeads) {
      out.push('snake-run');
      break;
    }
  }

  const tiles = Object.keys(board.mystery).map(Number).sort((a, b) => a - b);
  const { maxPerWindow, window, maxGap } = cfg.mysterySpacing;
  let spacingBad = false;
  for (let start = 1; start + window - 1 <= N - 1; start++) {
    const inWindow = tiles.filter((t) => t >= start && t < start + window).length;
    if (inWindow > maxPerWindow) spacingBad = true;
  }
  const marks = [0, ...tiles, N];
  for (let i = 1; i < marks.length; i++) if (marks[i]! - marks[i - 1]! > maxGap) spacingBad = true;
  if (spacingBad) out.push('mystery-spacing');

  return out;
}
```

```ts
import { jumpKind, type Board } from './types';

const RARITY_MARK = { common: 'c', rare: 'r', epic: 'e' } as const;

/**
 * Serpentine grid, 10 tiles per row, highest row first (spec §7.4).
 * Marks: S snake head, L ladder foot, c/r/e Mystery rarity, . plain.
 */
export function renderBoardAscii(board: Board): string {
  const width = 10;
  const rows = Math.ceil(board.size / width);
  const lines: string[] = [];
  for (let row = rows - 1; row >= 0; row--) {
    const tiles: number[] = [];
    for (let col = 0; col < width; col++) {
      const t = row * width + col + 1;
      if (t <= board.size) tiles.push(t);
    }
    if (row % 2 === 1) tiles.reverse();
    lines.push(tiles.map((t) => `${String(t).padStart(3)}${mark(board, t)}`).join(' '));
  }
  const fmt = (kind: 'snake' | 'ladder') =>
    board.jumps
      .filter((j) => jumpKind(j) === kind)
      .sort((a, b) => a.from - b.from)
      .map((j) => `${j.from}→${j.to}`)
      .join(', ');
  lines.push('');
  lines.push(`Snakes:  ${fmt('snake')}`);
  lines.push(`Ladders: ${fmt('ladder')}`);
  lines.push(`Seed: ${board.seed} (generator v${board.generatorVersion})`);
  return lines.join('\n');
}

function mark(board: Board, tile: number): string {
  const j = board.jumps.find((x) => x.from === tile);
  if (j) return jumpKind(j) === 'snake' ? 'S' : 'L';
  const rarity = board.mystery[tile];
  return rarity ? RARITY_MARK[rarity] : '.';
}
```

```ts
import type { Rarity } from '../board/types';
import { pickWeighted, type RngStream } from '../rng/stream';
import { CARD_TYPES, type CardDef, type CardType } from './types';

export function cardById(cards: readonly CardDef[], id: string): CardDef {
  const c = cards.find((card) => card.id === id);
  if (!c) throw new Error(`unknown card ${id}`);
  return c;
}

/**
 * Draw one card of `rarity` (spec §5.2): first a type by `typeWeights`, then a
 * card of that (type, rarity) bucket by card weight. `excludeId` is never drawn.
 */
export function drawCard(
  cards: readonly CardDef[],
  rarity: Rarity,
  typeWeights: Record<CardType, number>,
  stream: RngStream,
  excludeId?: string,
): string {
  const buckets = CARD_TYPES.map((type) =>
    cards.filter((c) => c.type === type && c.rarity === rarity && c.id !== excludeId),
  );
  const weights = CARD_TYPES.map((type, i) => (buckets[i]!.length > 0 ? typeWeights[type] : 0));
  const bucket = buckets[pickWeighted(stream, weights)]!;
  return bucket[pickWeighted(stream, bucket.map((c) => c.weight))]!.id;
}
```

```ts
export interface MatchConfig {

  board: BoardConfig;
  windows: { diceMs: number; bonusGraceMs: number; challengeMs: number; mysteryMs: number };
  mystery: { typeWeights: Record<CardType, number>; maxRerolls: number };

export interface MatchConfigInput {
  seed: string;
  board?: Partial<BoardConfig>;
  windows?: Partial<MatchConfig['windows']>;
  mystery?: Partial<MatchConfig['mystery']>;
  collision?: Partial<MatchConfig['collision']>;
  cards?: CardDef[];
  checkInvariants?: boolean;
}

export const DEFAULT_WINDOWS: MatchConfig['windows'] = {
  diceMs: 12_000,
  bonusGraceMs: 5_000,
  challengeMs: 8_000,
  mysteryMs: 15_000,
};

export function resolveConfig(input: MatchConfigInput): MatchConfig {
  if (typeof input.seed !== 'string' || input.seed.length === 0) throw new ConfigError('seed must be a non-empty string');
  const cfg: MatchConfig = {
    seed: input.seed,
    board: { ...DEFAULT_BOARD_CONFIG, ...input.board },
    windows: { ...DEFAULT_WINDOWS, ...input.windows },
    mystery: {
      typeWeights: { movement: 1, defense: 1, attack: 1, risky: 1, misc: 1 },
      maxRerolls: 2,
      ...input.mystery,
    },
    collision: { knockback: 3, maxReplays: 3, maxWaves: 3, ...input.collision },
    cards: input.cards ?? STARTER_CARDS,
    checkInvariants: input.checkInvariants ?? true,
  };
  validateConfig(cfg);
  return cfg;
}

export function validateConfig(cfg: MatchConfig): void {
  for (const [k, v] of Object.entries(cfg.windows)) {
    if (!Number.isInteger(v) || v <= 0) throw new ConfigError(`windows.${k} must be a positive integer, got ${v}`);
  }
  const { knockback, maxReplays, maxWaves } = cfg.collision;
  if (!Number.isInteger(knockback) || knockback < 1) throw new ConfigError('collision.knockback must be >= 1');
  if (!Number.isInteger(maxReplays) || maxReplays < 0) throw new ConfigError('collision.maxReplays must be >= 0');
  if (!Number.isInteger(maxWaves) || maxWaves < 1) throw new ConfigError('collision.maxWaves must be >= 1');
  if (!Number.isInteger(cfg.mystery.maxRerolls) || cfg.mystery.maxRerolls < 0 || cfg.mystery.maxRerolls > 3) {
    throw new ConfigError('mystery.maxRerolls must be 0..3');
  }
  validateCards(cfg.cards);
}

/** Every (type, rarity) bucket must hold at least one card with positive weight; ids must be unique. */
export function validateCards(cards: CardDef[]): void {
  const ids = new Set<string>();
  for (const c of cards) {
    if (ids.has(c.id)) throw new ConfigError(`duplicate card id ${c.id}`);
    ids.add(c.id);
    if (!Number.isInteger(c.weight) || c.weight <= 0) throw new ConfigError(`card ${c.id} weight must be a positive integer`);
    if (c.target.condition === 'section' && !c.target.section) throw new ConfigError(`card ${c.id} needs a section range`);
  }
  for (const type of CARD_TYPES) {
    for (const rarity of RARITIES) {
      if (!cards.some((c) => c.type === type && c.rarity === rarity)) {
        throw new ConfigError(`no card for bucket (${type}, ${rarity})`);
      }
    }
  }
}
```

```ts
import { nextInt, type RngStream } from '../rng/stream';
import type { TargetRule } from './types';

export interface TargetablePlayer {
  id: string;
  seat: number;
  position: number;
}

/** Players satisfying the rule's condition relative to the caster (spec §5.1). */
export function targetCandidates(players: readonly TargetablePlayer[], caster: TargetablePlayer, rule: TargetRule): TargetablePlayer[] {
  switch (rule.condition) {
    case 'self':
      return [caster];
    case 'other':
      return players.filter((p) => p.id !== caster.id);
    case 'ahead-of-caster':
      return players.filter((p) => p.id !== caster.id && p.position > caster.position);
    case 'behind-of-caster':
      return players.filter((p) => p.id !== caster.id && p.position < caster.position);
    case 'section': {
      const [lo, hi] = rule.section!;
      return players.filter((p) => p.id !== caster.id && p.position >= lo && p.position <= hi);
    }
  }
}

export function isValidTarget(
  players: readonly TargetablePlayer[],
  caster: TargetablePlayer,
  rule: TargetRule,
  targetId: string,
): boolean {
  return targetCandidates(players, caster, rule).some((p) => p.id === targetId);
}

/** Select exactly one target by the rule's pick + tieBreak, or null if no candidate qualifies. */
export function selectTarget(
  players: readonly TargetablePlayer[],
  caster: TargetablePlayer,
  rule: TargetRule,
  misc: RngStream,
): string | null {
  const candidates = targetCandidates(players, caster, rule);
  if (candidates.length === 0) return null;
  if (rule.pick === 'self') return candidates.some((p) => p.id === caster.id) ? caster.id : null;
  const score = (p: TargetablePlayer): number => {
    const d = Math.abs(p.position - caster.position);
    switch (rule.pick) {
      case 'nearest':
        return -d;
      case 'furthest':
        return d;
      case 'leader':
        return p.position;
      case 'last':
        return -p.position;
      case 'self':
        return 0;
    }
  };
  const best = Math.max(...candidates.map(score));
  const tied = candidates.filter((p) => score(p) === best).sort((a, b) => a.seat - b.seat);
  const chosen = rule.tieBreak === 'random' && tied.length > 1 ? tied[nextInt(misc, tied.length)]! : tied[0]!;
  return chosen.id;
}
```

```ts
import { boardViolations } from '../board/invariants';
import { jumpKind, jumpLength, type Board, type Jump, type JumpKind } from '../board/types';
import type { BoardEditOp } from './types';

export interface PlannedEdit {
  added: Jump[];
  removed: Jump[];
}

function withEdit(board: Board, edit: PlannedEdit): Board {
  const removedIds = new Set(edit.removed.map((j) => j.id));
  return { ...board, jumps: [...board.jumps.filter((j) => !removedIds.has(j.id)), ...edit.added] };
}

function isValid(board: Board, edit: PlannedEdit): boolean {
  return boardViolations(withEdit(board, edit)).length === 0;
}

/** Nearest jump of `kind` starting strictly ahead of `anchor`. */
function nearestAhead(board: Board, anchor: number, kind: JumpKind): Jump | undefined {
  return board.jumps
    .filter((j) => jumpKind(j) === kind && j.from > anchor)
    .sort((a, b) => a.from - b.from)[0];
}

function makeJump(id: string, from: number, kind: JumpKind, length: number): Jump {
  return { id, from, to: kind === 'snake' ? from - length : from + length };
}

/**
 * Plan a board edit anchored at the target's position (spec §5.7). Returns
 * null when no placement satisfies the hard invariants (the card fizzles).
 * Does not mutate the board.
 */
export function planBoardEdit(board: Board, op: BoardEditOp, anchor: number, newId: string): PlannedEdit | null {
  switch (op.action) {
    case 'create': {
      for (let ahead = op.minAhead; ahead <= op.maxAhead; ahead++) {
        const edit = { added: [makeJump(newId, anchor + ahead, op.kind, op.length)], removed: [] };
        if (isValid(board, edit)) return edit;
      }
      return null;
    }
    case 'remove': {
      const j = nearestAhead(board, anchor, op.kind);
      return j ? { added: [], removed: [j] } : null;
    }
    case 'move': {
      const j = nearestAhead(board, anchor, op.kind);
      if (!j) return null;
      for (let ahead = op.minAhead; ahead <= op.maxAhead; ahead++) {
        const edit = { added: [makeJump(newId, anchor + ahead, op.kind, jumpLength(j))], removed: [j] };
        if (isValid(board, edit)) return edit;
      }
      return null;
    }
    case 'modify': {
      const j = nearestAhead(board, anchor, op.kind);
      if (!j) return null;
      const length = jumpLength(j) + op.lengthDelta;
      if (length < 1) return null;
      const edit = { added: [makeJump(newId, j.from, op.kind, length)], removed: [j] };
      return isValid(board, edit) ? edit : null;
    }
  }
}

export function applyPlannedEdit(board: Board, edit: PlannedEdit): void {
  const removedIds = new Set(edit.removed.map((j) => j.id));
  board.jumps = [...board.jumps.filter((j) => !removedIds.has(j.id)), ...edit.added];
}

/**
 * Undo an expired edit: drop the jumps it added, then restore what it removed
 * where that is still valid. Returns restored and dropped jump ids.
 */
export function revertEdit(board: Board, edit: PlannedEdit): { restored: string[]; dropped: string[] } {
  const addedIds = new Set(edit.added.map((j) => j.id));
  board.jumps = board.jumps.filter((j) => !addedIds.has(j.id));
  const restored: string[] = [];
  const dropped: string[] = [];
  for (const j of edit.removed) {
    if (boardViolations({ ...board, jumps: [...board.jumps, j] }).length === 0) {
      board.jumps.push(j);
      restored.push(j.id);
    } else {
      dropped.push(j.id);
    }
  }
  return { restored, dropped };
}
```

```ts
import {
  CARD_TYPES,
  STARTER_CARDS,
  createMatch,
  scriptedStream,
  step,
  type Board,
  type CardDef,
  type GameEvent,
  type Input,
  type MatchConfigInput,
  type MatchState,
  type Rarity,
} from '../../src/index';

export function makeBoard(size: number, jumps: Array<[number, number]> = [], mystery: Record<number, Rarity> = {}): Board {
  return {
    size,
    jumps: jumps.map(([from, to], i) => ({ id: `t${i + 1}`, from, to })),
    mystery,
    seed: 'test',
    generatorVersion: 1,
  };
}

/** Scripted dice stream: faces are 1..6. */
export function dice(...faces: number[]) {
  return scriptedStream(faces.map((f) => f - 1));
}

export interface Setup {
  board?: Board;
  players?: number;
  positions?: number[];
  dice?: number[][];
  misc?: number[];
  cards?: number[][];
  config?: Omit<MatchConfigInput, 'seed'>;
}

/** A match in round 1's dice window with a hand-built board and optional scripted streams. */
export function setup(opts: Setup = {}): MatchState {
  const n = opts.players ?? 2;
  const seats = Array.from({ length: n }, (_, i) => ({ id: `p${i + 1}` }));
  const s = createMatch({ seed: 'test', ...opts.config }, seats, opts.board ?? makeBoard(100));
  opts.positions?.forEach((pos, i) => {
    s.players[i]!.position = pos;
  });
  opts.dice?.forEach((faces, i) => {
    s.rng.dice[i] = dice(...faces);
  });
  if (opts.misc) s.rng.misc = scriptedStream(opts.misc);
  opts.cards?.forEach((vals, i) => {
    s.rng.cards[i] = scriptedStream(vals);
  });
  return s;
}

/** Apply inputs in order; throws if any is rejected. */
export function play(s: MatchState, inputs: Array<Input | ((cur: MatchState) => Input)>): { state: MatchState; events: GameEvent[] } {
  let cur = s;
  const events: GameEvent[] = [];
  for (const item of inputs) {
    const input = typeof item === 'function' ? item(cur) : item;
    const r = step(cur, input);
    if (!r.ok) throw new Error(`${JSON.stringify(input)} rejected: ${r.error.code} ${r.error.message}`);
    cur = r.state;
    events.push(...r.events);
  }
  return { state: cur, events };
}

export const roll = (player: string): Input => ({ type: 'roll', player });
export const stop = (player: string): Input => ({ type: 'bonusChoice', player, rollAgain: false });
export const again = (player: string): Input => ({ type: 'bonusChoice', player, rollAgain: true });
export const pick = (player: string, slot: number): Input => ({ type: 'pickCard', player, slot });
export const reroll = (player: string, slot: number): Input => ({ type: 'reroll', player, slot });
/** Timeout for whatever window is current when the input is applied. */
export const timeout = (cur: MatchState): Input => ({ type: 'timeout', windowId: cur.windowId });

/** Pick in the open challenge containing `player`. */
export const choose =
  (player: string, choice: 'rock' | 'paper' | 'scissors' | 'A' | 'B') =>
  (cur: MatchState): Input => {
    if (cur.phase.kind !== 'settle') throw new Error('no challenge open');
    const ch = cur.phase.ctx.challenges.find((c) => c.winner === null && c.contesting.includes(player));
    if (!ch) throw new Error(`${player} is not in an open challenge`);
    return { type: 'challengePick', player, challengeId: ch.id, choice };
  };

export function ofType<T extends GameEvent['type']>(events: GameEvent[], type: T): Array<Extract<GameEvent, { type: T }>> {
  return events.filter((e): e is Extract<GameEvent, { type: T }> => e.type === type);
}

export function positions(s: MatchState): number[] {
  return s.players.map((p) => p.position);
}

/**
 * Scripted card-stream values that make drawCard() return `cardId`
 * (type pick by weight, then card pick by weight within the bucket).
 */
export function drawValues(cardId: string, excludeId?: string, cards: CardDef[] = STARTER_CARDS): number[] {
  const card = cards.find((c) => c.id === cardId)!;
  const buckets = CARD_TYPES.map((t) => cards.filter((c) => c.type === t && c.rarity === card.rarity && c.id !== excludeId));
  const typeIdx = CARD_TYPES.indexOf(card.type);
  const typeValue = buckets.slice(0, typeIdx).filter((b) => b.length > 0).length;
  const bucket = buckets[typeIdx]!;
  const cardIdx = bucket.findIndex((c) => c.id === cardId);
  const cardValue = bucket.slice(0, cardIdx).reduce((a, c) => a + c.weight, 0);
  return [typeValue, cardValue];
}

/** Values for three offered cards. */
export function offerValues(...ids: [string, string, string]): number[] {
  return ids.flatMap((id) => drawValues(id));
}
```

```ts
  cause: MoveCause,
  bounced = false,
): void {
  const p = getPlayer(s, id);
  if (!Number.isInteger(to) || to < 0 || to > s.board.size) throw new InvariantError(`bad destination ${to}`);
  if (p.position === to && !bounced) return;
  ev.push(pub({ type: 'Moved', player: id, from: p.position, to, cause, bounced }));
  p.position = to;
  if (!s.movedThisRound.includes(id)) s.movedThisRound.push(id);
}

export function windowDuration(s: MatchState, window: WindowKind): number {
  switch (window) {
    case 'dice':
      return s.config.windows.diceMs;
    case 'bonusGrace':
      return s.config.windows.bonusGraceMs;
    case 'challenge':
      return s.config.windows.challengeMs;
    case 'mystery':
      return s.config.windows.mysteryMs;
    case 'none':
      return 0;
  }
}

export function openWindow(s: MatchState, ev: GameEvent[], window: WindowKind, players: PlayerId[]): void {
  s.windowId += 1;
  ev.push(pub({ type: 'WindowOpened', windowId: s.windowId, window, players, durationMs: windowDuration(s, window) }));
}

/** Tiles in 1..N occupied by two or more players, ascending. */
export function sharedTiles(s: MatchState): number[] {
  const counts = new Map<number, number>();
  for (const p of s.players) if (p.position >= 1) counts.set(p.position, (counts.get(p.position) ?? 0) + 1);
  return [...counts.entries()].filter(([, c]) => c >= 2).map(([t]) => t).sort((a, b) => a - b);
}

export function seatOrder(s: MatchState, ids: Iterable<PlayerId>): PlayerId[] {
  const set = new Set(ids);
  return s.players.filter((p) => set.has(p.id)).map((p) => p.id);
}
```

```ts
import type { GameEvent, MatchState, PlayerId } from './types';
import { clonePlain, nextId, pub } from './util';

type ParamsOf<H extends EffectHook> = Extract<EffectParams, { hook: H }>;
type EffectWith<H extends EffectHook> = ActiveEffect & { params: ParamsOf<H> };

/** The owner's effects on one hook, oldest first. */
export function effectsOn<H extends EffectHook>(s: MatchState, owner: PlayerId, hook: H): EffectWith<H>[] {
  return s.effects
    .filter((e): e is EffectWith<H> => e.owner === owner && e.params.hook === hook)
    .sort((a, b) => a.seq - b.seq);
}

export function addEffect(
  s: MatchState,
  ev: GameEvent[],
  owner: PlayerId,
  template: EffectTemplate,
  sourceCard: string,
  sourcePlayer: PlayerId,
): ActiveEffect {
  const id = nextId(s, 'e');
  const effect: ActiveEffect = {
    id,
    owner,
    sourceCard,
    sourcePlayer,
    params: clonePlain(template.params),
    lifetime: clonePlain(template.lifetime),
    createdRound: s.round,
    seq: s.counter,
  };
  s.effects.push(effect);
  ev.push(pub({ type: 'EffectAdded', effect: clonePlain(effect) }));
  return effect;
}

export function removeEffect(s: MatchState, ev: GameEvent[], effectId: string, reason: 'card' | 'charges'): void {
  const idx = s.effects.findIndex((e) => e.id === effectId);
  if (idx < 0) return;
  const [e] = s.effects.splice(idx, 1);
  ev.push(pub({ type: 'EffectRemoved', effectId, owner: e!.owner, reason }));
}

/** The effect fired once: spend a charge if it has charges, removing it at 0. */
export function spendCharge(s: MatchState, ev: GameEvent[], effect: ActiveEffect): void {
  if (effect.lifetime === 'permanent' || effect.lifetime.charges === undefined) return;
  effect.lifetime.charges -= 1;
  if (effect.lifetime.charges <= 0) removeEffect(s, ev, effect.id, 'charges');
}

/** FACE stage (spec §5.6): applied to each die before the 6-check. */
export function applyFaceEffects(
  s: MatchState,
  ev: GameEvent[],
  player: PlayerId,
  dieIndex: number,
  natural: number,
): { face: number; forced: boolean } {
  let face = natural;
  let forced = false;
  for (const e of effectsOn(s, player, 'diceFace')) {
    if (e.params.die === 'each' || dieIndex === 0) {
      face = e.params.set;
      forced = true;
      spendCharge(s, ev, e);
    }
  }
  return { face, forced };
}

/** TOTAL stage (spec §5.6): Replace (newest wins) → Multiply (product) → Add (sum) → floor 0. All diceTotal effects fire. */
export function applyTotalEffects(s: MatchState, ev: GameEvent[], player: PlayerId, sum: number): number {
  const effects = effectsOn(s, player, 'diceTotal');
  let total = sum;
  const replaces = effects.filter((e) => e.params.op === 'replace');
  if (replaces.length > 0) total = replaces[replaces.length - 1]!.params.value;
  for (const e of effects) if (e.params.op === 'multiply') total *= e.params.value;
  for (const e of effects) if (e.params.op === 'add') total += e.params.value;
  for (const e of effects) spendCharge(s, ev, e);
  return Math.max(0, Math.trunc(total));
}

/** Returns the id of the effect that cancelled the snake, or null. */
export function useSnakeShield(s: MatchState, ev: GameEvent[], player: PlayerId): string | null {
  const shield = effectsOn(s, player, 'beforeSnake')[0];
  if (!shield) return null;
  spendCharge(s, ev, shield);
  return shield.id;
}

/** Returns the id of the effect that blocked the attack, or null. */
export function useAttackShield(s: MatchState, ev: GameEvent[], player: PlayerId): string | null {
  const shield = effectsOn(s, player, 'beforeAttack')[0];
  if (!shield) return null;
  spendCharge(s, ev, shield);
  return shield.id;
}

/**
 * afterMove conditionals (spec §4.5 step 1). Every matching effect fires (spends
 * a charge); those whose condition holds contribute their amount. Returns the
 * total extra movement.
 */
export function evaluateAfterMove(
  s: MatchState,
  ev: GameEvent[],
  player: PlayerId,
  cause: MoveCause,
  landedOn: number,
  boardForCheck = s.board,
): number {
  let extra = 0;
  for (const e of effectsOn(s, player, 'afterMove')) {
    if (e.params.cause !== cause) continue;
    if (e.params.condition === 'landedOnSnakeHead' && isSnakeHead(boardForCheck, landedOn)) extra += e.params.amount;
    spendCharge(s, ev, e);
  }
  return extra;
}

/** Round end (spec §4.11): remove effects whose `rounds` lifetime has run out. */
export function expireEffects(s: MatchState, ev: GameEvent[]): void {
  const keep: ActiveEffect[] = [];
  for (const e of s.effects) {
    const rounds = e.lifetime === 'permanent' ? undefined : e.lifetime.rounds;
    if (rounds !== undefined && s.round >= e.createdRound + rounds) {
      ev.push(pub({ type: 'EffectExpired', effectId: e.id, owner: e.owner }));
    } else {
      keep.push(e);
    }
  }
  s.effects = keep;
}
```

```ts
type DicePhase = Extract<MatchState['phase'], { kind: 'dice' }>;

export function inputError(code: InputError['code'], message: string): InputError {
  return { code, message };
}

export function startDicePhase(s: MatchState, ev: GameEvent[]): void {
  const seqs: Record<PlayerId, DiceSeq> = {};
  for (const p of s.players) seqs[p.id] = { faces: [], status: 'ready' };
  s.phase = { kind: 'dice', window: 'dice', seqs };
  openWindow(s, ev, 'dice', s.players.map((p) => p.id));
}

function dicePhase(s: MatchState): DicePhase | null {
  return s.phase.kind === 'dice' ? s.phase : null;
}

/** Roll one die for the player; a first-die 6 opens the bonus choice (spec §4.3). */
function rollOne(s: MatchState, ev: GameEvent[], player: PlayerId, auto: boolean): void {
  const phase = dicePhase(s)!;
  const seq = phase.seqs[player]!;
  const seat = getPlayer(s, player).seat;
  const natural = rollDie(s.rng.dice[seat]!);
  const { face, forced } = applyFaceEffects(s, ev, player, seq.faces.length, natural);
  seq.faces.push(face);
  ev.push(pub({ type: 'DieRolled', player, natural, face, forced, auto }));
  seq.status = face === 6 && seq.faces.length === 1 ? 'bonusPending' : 'done';
}

export function rollInput(s: MatchState, ev: GameEvent[], player: PlayerId): InputError | null {
  const phase = dicePhase(s);
  if (!phase) return inputError('WRONG_PHASE', 'not in the dice phase');
  const seq = phase.seqs[player];
  if (!seq) return inputError('UNKNOWN_PLAYER', `unknown player ${player}`);
  if (phase.window !== 'dice' || seq.status !== 'ready') return inputError('NOT_AWAITED', `${player} cannot roll now`);
  rollOne(s, ev, player, false);
  return null;
}

export function bonusChoiceInput(s: MatchState, ev: GameEvent[], player: PlayerId, rollAgain: boolean): InputError | null {
  const phase = dicePhase(s);
  if (!phase) return inputError('WRONG_PHASE', 'not in the dice phase');
  const seq = phase.seqs[player];
  if (!seq) return inputError('UNKNOWN_PLAYER', `unknown player ${player}`);
  if (seq.status !== 'bonusPending') return inputError('NOT_AWAITED', `${player} has no bonus roll pending`);
  ev.push(pub({ type: 'BonusChosen', player, rollAgain, auto: false }));
  if (rollAgain) rollOne(s, ev, player, false);
  else seq.status = 'done';
  return null;
}

/**
 * Dice window expiry: auto-roll anyone who has not rolled, then open one
 * bonusGrace window if any bonus choice is pending. Grace expiry = Stop.
 */
export function diceTimeout(s: MatchState, ev: GameEvent[]): void {
  const phase = dicePhase(s)!;
  if (phase.window === 'dice') {
    for (const p of s.players) if (phase.seqs[p.id]!.status === 'ready') rollOne(s, ev, p.id, true);
    const pending = s.players.filter((p) => phase.seqs[p.id]!.status === 'bonusPending').map((p) => p.id);
    if (pending.length > 0) {
      phase.window = 'bonusGrace';
      openWindow(s, ev, 'bonusGrace', pending);
    }
    return;
  }
  for (const p of s.players) {
    const seq = phase.seqs[p.id]!;
    if (seq.status === 'bonusPending') {
      ev.push(pub({ type: 'BonusChosen', player: p.id, rollAgain: false, auto: true }));
      seq.status = 'done';
    }
  }
}

export function diceAwaited(phase: DicePhase): PlayerId[] {
  return Object.entries(phase.seqs)
    .filter(([, seq]) => (phase.window === 'dice' ? seq.status !== 'done' : seq.status === 'bonusPending'))
    .map(([id]) => id);
}

export function diceComplete(phase: DicePhase): boolean {
  return Object.values(phase.seqs).every((seq) => seq.status === 'done');
}

/** Totals with TOTAL-stage effects, then simultaneous movement with bounce (spec §4.3–4.4). */
export function finishDicePhase(s: MatchState, ev: GameEvent[]): void {
  const phase = dicePhase(s)!;
  const N = s.board.size;
  const movers: Mover[] = [];
  for (const p of s.players) {
    const seq = phase.seqs[p.id]!;
    const sum = seq.faces.reduce((a, b) => a + b, 0);
    const total = applyTotalEffects(s, ev, p.id, sum);
    s.lastTotals[p.id] = total;
    ev.push(pub({ type: 'DiceTotaled', player: p.id, faces: [...seq.faces], total }));
  }
  for (const p of s.players) {
    const total = s.lastTotals[p.id]!;
    if (total === 0) continue;
    const raw = p.position + total;
    movePlayer(s, ev, p.id, bounce(raw, N), 'dice', raw > N);
    movers.push({ player: p.id, cause: 'dice' });
  }
  s.phase = { kind: 'settle', ctx: { movers, wave: 0, challenges: [] }, after: 'mysteryDetect' };
}
```

```ts
export function rankPlayers(s: MatchState): Ranking[] {
  return [...s.players]
    .sort((a, b) => b.position - a.position || a.seat - b.seat)
    .map((p) => ({
      player: p.id,
      position: p.position,
      rank: 1 + s.players.filter((o) => o.position > p.position).length,
    }));

/** Round end (spec §4.11): lifetimes tick, victory check, next round. */
export function endRound(s: MatchState, ev: GameEvent[]): void {
  expireEffects(s, ev);
  const keep = [];
  for (const edit of s.boardEdits) {
    if (edit.lifetime !== 'permanent' && s.round >= edit.createdRound + edit.lifetime.rounds) {
      const { restored, dropped } = revertEdit(s.board, edit);
      ev.push(pub({ type: 'BoardEditExpired', editId: edit.id, restored, dropped }));
    } else {
      keep.push(edit);
    }
  }
  s.boardEdits = keep;
  ev.push(pub({ type: 'RoundEnded', round: s.round }));

  const winner = s.players.find((p) => p.position === s.board.size);
  if (winner) {
    const rankings = rankPlayers(s);
    s.phase = { kind: 'finished', winner: winner.id, rankings };
    s.windowId += 1;
    ev.push(pub({ type: 'MatchWon', winner: winner.id, rankings }));
    return;
  }
  startRound(s, ev);
}
```

```ts
export function assertInvariants(s: MatchState): void {

  for (const p of s.players) {
```

```ts
/** JSON with object keys sorted, so equal states always serialize identically. */
export function stableStringify(value: unknown): string {
  if (value === null || typeof value !== 'object') return JSON.stringify(value);
  if (Array.isArray(value)) return `[${value.map((v) => (v === undefined ? 'null' : stableStringify(v))).join(',')}]`;
  const obj = value as Record<string, unknown>;
  const keys = Object.keys(obj).filter((k) => obj[k] !== undefined).sort();
  return `{${keys.map((k) => `${JSON.stringify(k)}:${stableStringify(obj[k])}`).join(',')}}`;
}
```

```ts
import { bonusChoiceInput, diceComplete, diceTimeout, finishDicePhase, inputError, rollInput } from './dice';
import { assertInvariants } from './invariants';
import { endRound } from './round';
import type { GameEvent, Input, InputError, MatchState, StepResult } from './types';
import { clonePlain } from './util';

/** Apply one input. Pure from the outside: the given state is never mutated (spec §3.2). */
export function step(state: MatchState, input: Input): StepResult {
  if (state.phase.kind === 'finished') {
    return { ok: false, error: inputError('MATCH_FINISHED', 'the match is over') };
  }
  // config is never mutated, so it is shared rather than cloned (it holds the whole card list).
  const { config, ...rest } = state;
  const s: MatchState = { ...clonePlain(rest), config };
  const ev: GameEvent[] = [];
  const error = dispatch(s, ev, input);
  if (error) return { ok: false, error };
  advance(s, ev);
  if (s.config.checkInvariants) assertInvariants(s);
  return { ok: true, state: s, events: ev };
}

function dispatch(s: MatchState, ev: GameEvent[], input: Input): InputError | null {
  if (input.type !== 'timeout' && !s.players.some((p) => p.id === input.player)) {
    return inputError('UNKNOWN_PLAYER', `unknown player ${input.player}`);
  }
  switch (input.type) {
    case 'roll':
      return rollInput(s, ev, input.player);
    case 'bonusChoice':
      return bonusChoiceInput(s, ev, input.player, input.rollAgain);
    case 'timeout':
      return timeout(s, ev, input.windowId);
    default:
      // Challenges arrive in Task 10, Mystery cards in Task 11.
      return inputError('WRONG_PHASE', `${input.type} is not possible in the ${s.phase.kind} phase`);
  }
}

function timeout(s: MatchState, ev: GameEvent[], windowId: number): InputError | null {
  if (windowId !== s.windowId) return inputError('STALE_TIMEOUT', `window ${windowId} is not the current window ${s.windowId}`);
  if (s.phase.kind !== 'dice') return inputError('WRONG_PHASE', 'no open window to time out');
  diceTimeout(s, ev);
  return null;
}

/** Run the state machine forward until it needs player input or the match ends. */
export function advance(s: MatchState, ev: GameEvent[]): void {
  for (;;) {
    const phase = s.phase;
    switch (phase.kind) {
      case 'dice':
        if (!diceComplete(phase)) return;
        finishDicePhase(s, ev);
        break;
      case 'settle':
        // Task 10 replaces this with the settle loop (snakes, ladders, collisions).
        endRound(s, ev);
        break;
      case 'mysterySelect':
      case 'finished':
        return;
    }
  }
}
```

```ts
import { nextInt, pickOne, type RngStream } from '../rng/stream';
import { inputError } from './dice';
import type { Challenge, ChallengeChoice, GameEvent, InputError, MatchState, PlayerId, RpsChoice } from './types';
import { nextId, openWindow, priv, pub } from './util';

export const MINORITY_THEMES: ReadonlyArray<[string, string]> = [
  ['Snake', 'Ladder'],
  ['Sun', 'Moon'],
  ['Attack', 'Defend'],
  ['Fish', 'Chicken'],
];

const BEATS: Record<RpsChoice, RpsChoice> = { rock: 'scissors', scissors: 'paper', paper: 'rock' };

export function createChallenge(s: MatchState, ev: GameEvent[], tile: number, participants: PlayerId[]): Challenge {
  const kind = participants.length === 2 ? 'rps' : 'minority';
  const theme: [string, string] | null = kind === 'minority' ? [...pickOne(s.rng.misc, MINORITY_THEMES)] : null;
  const ch: Challenge = {
    id: nextId(s, 'c'),
    tile,
    participants: [...participants],
    contesting: [...participants],
    kind,
    theme,
    pickRound: 1,
    picks: {},
    losers: [],
    winner: null,
  };
  ev.push(pub({ type: 'ChallengeStarted', challengeId: ch.id, tile, players: [...participants], kind, theme }));
  return ch;
}

function isValidChoice(kind: Challenge['kind'], choice: ChallengeChoice): boolean {
  return kind === 'rps' ? choice === 'rock' || choice === 'paper' || choice === 'scissors' : choice === 'A' || choice === 'B';
}

export type PickRoundOutcome = 'win' | 'replay' | 'continue' | 'random';

/**
 * Close one picking round of a challenge (spec §4.7). Mutates `ch`.
 * `timedOut` lists contesting players who did not pick in time.
 */
export function resolvePickRound(ch: Challenge, timedOut: PlayerId[], misc: RngStream, maxPickRounds: number): PickRoundOutcome {
  const roundPlayers = [...ch.contesting];
  const lose = (ids: PlayerId[]) => {
    for (const id of ids) if (!ch.losers.includes(id)) ch.losers.push(id);
    ch.contesting = ch.contesting.filter((id) => !ids.includes(id));
  };
  const win = (id: PlayerId) => {
    ch.winner = id;
    lose(ch.contesting.filter((p) => p !== id));
  };

  lose(timedOut.filter((id) => ch.contesting.includes(id)));

  if (ch.contesting.length === 0) {
    // Everyone timed out: pick a random winner among this round's contestants.
    ch.losers = ch.losers.filter((id) => !roundPlayers.includes(id));
    ch.contesting = [...roundPlayers];
    win(roundPlayers[nextInt(misc, roundPlayers.length)]!);
    return 'random';
  }
  if (ch.contesting.length === 1) {
    win(ch.contesting[0]!);
    return 'win';
  }

  let outcome: 'replay' | 'continue' | 'win';
  if (ch.contesting.length === 2 && ch.kind === 'minority') {
    // A minority challenge narrowed to two players continues as RPS.
    ch.kind = 'rps';
    outcome = 'continue';
  } else if (ch.kind === 'rps') {
    const [a, b] = ch.contesting as [PlayerId, PlayerId];
    const pa = ch.picks[a] as RpsChoice;
    const pb = ch.picks[b] as RpsChoice;
    if (pa === pb) outcome = 'replay';
    else {
      win(BEATS[pa] === pb ? a : b);
      outcome = 'win';
    }
  } else {
    const sideA = ch.contesting.filter((id) => ch.picks[id] === 'A');
    const sideB = ch.contesting.filter((id) => ch.picks[id] === 'B');
    if (sideA.length === 0 || sideB.length === 0 || sideA.length === sideB.length) outcome = 'replay';
    else {
      const [minority, majority] = sideA.length < sideB.length ? [sideA, sideB] : [sideB, sideA];
      lose(majority);
      if (minority.length === 1) {
        win(minority[0]!);
        outcome = 'win';
      } else {
        if (minority.length === 2) ch.kind = 'rps';
        outcome = 'continue';
      }
    }
  }

  if (outcome === 'win') return 'win';
  ch.pickRound += 1;
  ch.picks = {};
  if (ch.pickRound > maxPickRounds) {
    win(ch.contesting[nextInt(misc, ch.contesting.length)]!);
    return 'random';
  }
  return outcome;
}

type SettlePhase = Extract<MatchState['phase'], { kind: 'settle' }>;

export function openChallenges(s: MatchState): Challenge[] {
  return s.phase.kind === 'settle' ? s.phase.ctx.challenges.filter((c) => c.winner === null) : [];
}

export function challengeAwaited(s: MatchState): PlayerId[] {
  return openChallenges(s).flatMap((c) => c.contesting.filter((id) => c.picks[id] === undefined));
}

export function challengePickInput(
  s: MatchState,
  ev: GameEvent[],
  player: PlayerId,
  challengeId: string,
  choice: ChallengeChoice,
): InputError | null {
  if (s.phase.kind !== 'settle') return inputError('WRONG_PHASE', 'no challenge in progress');
  const ch = openChallenges(s).find((c) => c.id === challengeId);
  if (!ch) return inputError('UNKNOWN_CHALLENGE', `no open challenge ${challengeId}`);
  if (!ch.contesting.includes(player) || ch.picks[player] !== undefined) {
    return inputError('NOT_AWAITED', `${player} cannot pick in ${challengeId}`);
  }
  if (!isValidChoice(ch.kind, choice)) return inputError('INVALID_CHOICE', `${choice} is not valid for ${ch.kind}`);
  ch.picks[player] = choice;
  ev.push(pub({ type: 'ChallengePickLocked', challengeId, player }));
  ev.push(priv(player, { type: 'ChallengePickEcho', challengeId, player, choice }));
  if (challengeAwaited(s).length === 0) closePickRound(s, ev);
  return null;
}

/** Close the current picking round of every open challenge (all picked, or timeout). */
export function closePickRound(s: MatchState, ev: GameEvent[]): void {
  const phase = s.phase as SettlePhase;
  const maxPickRounds = s.config.collision.maxReplays + 1;
  for (const ch of openChallenges(s)) {
    const timedOut = ch.contesting.filter((id) => ch.picks[id] === undefined);
    const picks: Record<PlayerId, ChallengeChoice | null> = {};
    for (const id of ch.contesting) picks[id] = ch.picks[id] ?? null;
    const pickRound = ch.pickRound;
    const outcome = resolvePickRound(ch, timedOut, s.rng.misc, maxPickRounds);
    ev.push(
      pub({
        type: 'ChallengeResolved',
        challengeId: ch.id,
        pickRound,
        picks,
        winner: ch.winner,
        losers: ch.winner ? [...ch.losers] : [],
        outcome,
      }),
    );
  }
  const stillOpen = phase.ctx.challenges.filter((c) => c.winner === null);
  if (stillOpen.length > 0) openWindow(s, ev, 'challenge', stillOpen.flatMap((c) => c.contesting));
}
```

```ts
import { jumpFrom } from '../board/types';
import { nextInt } from '../rng/stream';
import { createChallenge } from './challenge';
import { evaluateAfterMove, useSnakeShield } from './effects';
import { InvariantError } from './errors';
import type { GameEvent, MatchState, Mover, PlayerId } from './types';
import { bounce, getPlayer, movePlayer, openWindow, pub, seatOrder, sharedTiles } from './util';

type SettlePhase = Extract<MatchState['phase'], { kind: 'settle' }>;

/**
 * Step 1 of the settle loop: every mover follows snake/ladder chains, then its
 * afterMove conditionals fire. Returns all players who moved in this step.
 */
export function resolveJumps(s: MatchState, ev: GameEvent[], movers: Mover[]): Mover[] {
  const queue = [...movers];
  const moved = new Map<PlayerId, Mover>();
  while (queue.length > 0) {
    const m = queue.shift()!;
    moved.set(m.player, m);
    const p = getPlayer(s, m.player);
    const landedOn = p.position;
    let guard = 0;
    for (;;) {
      const j = jumpFrom(s.board, p.position);
      if (!j) break;
      if (j.to < j.from) {
        const shield = useSnakeShield(s, ev, p.id);
        if (shield) {
          ev.push(pub({ type: 'SnakeBlocked', player: p.id, tile: p.position, effectId: shield }));
          break;
        }
        movePlayer(s, ev, p.id, j.to, 'snake');
      } else {
        movePlayer(s, ev, p.id, j.to, 'ladder');
      }
      if (++guard > s.board.jumps.length) throw new InvariantError('jump cycle while settling');
    }
    const extra = evaluateAfterMove(s, ev, p.id, m.cause, landedOn);
    if (extra !== 0) {
      const raw = p.position + extra;
      movePlayer(s, ev, p.id, bounce(raw, s.board.size), 'effect', raw > s.board.size);
      queue.push({ player: p.id, cause: 'effect' });
    }
  }
  return [...moved.values()];
}

/**
 * Safety cap (spec §4.6): players who arrived on a shared tile in this step step
 * back to the nearest free tile, triggering nothing. If every occupant arrived
 * now, `misc` picks one to stay.
 */
export function applySafetyCap(s: MatchState, ev: GameEvent[], movers: Mover[]): void {
  const arrived = new Set(movers.map((m) => m.player));
  for (const tile of sharedTiles(s)) {
    const occupants = seatOrder(s, s.players.filter((p) => p.position === tile).map((p) => p.id));
    let steppers = occupants.filter((id) => arrived.has(id));
    if (steppers.length === occupants.length) {
      const stay = occupants[nextInt(s.rng.misc, occupants.length)]!;
      steppers = occupants.filter((id) => id !== stay);
    }
    for (const id of steppers) {
      let to = tile - 1;
      while (to > 0 && s.players.some((p) => p.position === to)) to--;
      movePlayer(s, ev, id, to, 'stepBack');
    }
    ev.push(pub({ type: 'SafetyCapApplied', tile, steppedBack: steppers }));
  }
}

/**
 * Run the settle loop (spec §4.5) until it needs challenge picks ('waiting')
 * or no tile in 1..N is shared ('done').
 */
export function runSettle(s: MatchState, ev: GameEvent[]): 'waiting' | 'done' {
  const phase = s.phase as SettlePhase;
  const ctx = phase.ctx;
  for (;;) {
    if (ctx.challenges.length > 0) {
      if (ctx.challenges.some((c) => c.winner === null)) return 'waiting';
      const knocked: Mover[] = [];
      for (const ch of ctx.challenges) {
        for (const loser of seatOrder(s, ch.losers)) {
          const p = getPlayer(s, loser);
          movePlayer(s, ev, loser, Math.max(0, p.position - s.config.collision.knockback), 'knockback');
          knocked.push({ player: loser, cause: 'knockback' });
        }
      }
      ctx.challenges = [];
      ctx.movers = knocked;
    }

    ctx.movers = resolveJumps(s, ev, ctx.movers);
    const shared = sharedTiles(s);
    if (shared.length === 0) return 'done';
    if (ctx.wave >= s.config.collision.maxWaves) {
      applySafetyCap(s, ev, ctx.movers);
      return 'done';
    }
    ctx.wave += 1;
    ctx.challenges = shared.map((tile) =>
      createChallenge(s, ev, tile, seatOrder(s, s.players.filter((p) => p.position === tile).map((p) => p.id))),
    );
    openWindow(s, ev, 'challenge', ctx.challenges.flatMap((c) => c.contesting));
    return 'waiting';
  }
}
```

```ts
  advance(s, ev);
  if (s.config.checkInvariants) assertInvariants(s);
  return { ok: true, state: s, events: ev };
}

function dispatch(s: MatchState, ev: GameEvent[], input: Input): InputError | null {
  if (input.type !== 'timeout' && !s.players.some((p) => p.id === input.player)) {
    return inputError('UNKNOWN_PLAYER', `unknown player ${input.player}`);
  }
  switch (input.type) {
    case 'roll':
      return rollInput(s, ev, input.player);
    case 'bonusChoice':
      return bonusChoiceInput(s, ev, input.player, input.rollAgain);
    case 'challengePick':
      return challengePickInput(s, ev, input.player, input.challengeId, input.choice);
    case 'timeout':
      return timeout(s, ev, input.windowId);
    default:
      // Mystery cards arrive in Task 11.
      return inputError('WRONG_PHASE', `${input.type} is not possible in the ${s.phase.kind} phase`);
  }
}

function timeout(s: MatchState, ev: GameEvent[], windowId: number): InputError | null {
  if (windowId !== s.windowId) return inputError('STALE_TIMEOUT', `window ${windowId} is not the current window ${s.windowId}`);
  switch (s.phase.kind) {
    case 'dice':
      diceTimeout(s, ev);
      return null;
    case 'settle':
      closePickRound(s, ev);
      return null;
    default:
      return inputError('WRONG_PHASE', 'no open window to time out');
  }
}

/** Run the state machine forward until it needs player input or the match ends. */
export function advance(s: MatchState, ev: GameEvent[]): void {
  for (;;) {
    const phase = s.phase;
    switch (phase.kind) {
      case 'dice':
        if (!diceComplete(phase)) return;
        finishDicePhase(s, ev);
        break;
      case 'settle':
        if (runSettle(s, ev) === 'waiting') return;
        // Task 11 inserts Mystery detection and card resolution here.
        endRound(s, ev);
        break;
      case 'mysterySelect':
      case 'finished':
        return;
    }
  }
}
```

```ts
import { jumpKind } from '../board/types';
import { applyPlannedEdit, planBoardEdit } from '../cards/boardEdit';
import { cardById } from '../cards/catalog';
import { isValidTarget, selectTarget } from '../cards/targeting';
import { CARD_TYPES, RARITY_ORDER, type CardDef, type EffectOp, type EffectTemplate } from '../cards/types';
import { pickWeighted } from '../rng/stream';
import { addEffect, removeEffect, useAttackShield } from './effects';
import type { BoardEdit, CardResult, GameEvent, MatchState, Mover, PendingCard, PlayerId } from './types';
import { bounce, clonePlain, getPlayer, movePlayer, nextId, pub, seatOrder } from './util';

/** Order pending cards into resolution groups: type, then rarity; same type+rarity = one group (spec §5.4). */
export function groupPendingCards(cards: readonly CardDef[], pending: PendingCard[]): PendingCard[][] {
  const groups: PendingCard[][] = [];
  for (const type of CARD_TYPES) {
    for (const rarity of RARITY_ORDER) {
      const group = pending.filter((pc) => {
        const c = cardById(cards, pc.cardId);
        return c.type === type && c.rarity === rarity;
      });
      if (group.length > 0) groups.push(group);
    }
  }
  return groups;
}

interface CardIntents {
  deltas: Array<{ player: PlayerId; amount: number }>;
  placements: Array<Array<{ player: PlayerId; tile: number }>>;
  adds: Array<{ owner: PlayerId; template: EffectTemplate }>;
  removals: string[];
  edits: Array<Extract<EffectOp, { op: 'boardEdit' }>>;
}

interface CardOutcome {
  pc: PendingCard;
  card: CardDef;
  target: PlayerId | null;
  result: CardResult;
  reason?: 'no-target' | 'no-placement' | 'clash';
  intents: CardIntents | null;
}

/** Expand a card's ops against the current (snapshot) state. Returns null if an op has no valid placement. */
function collectIntents(s: MatchState, card: CardDef, caster: PlayerId, target: PlayerId): CardIntents | null {
  const intents: CardIntents = { deltas: [], placements: [], adds: [], removals: [], edits: [] };
  const targetPos = getPlayer(s, target).position;
  const visit = (op: EffectOp): boolean => {
    switch (op.op) {
      case 'moveRelative':
        intents.deltas.push({ player: target, amount: op.amount });
        return true;
      case 'moveTo': {
        const foot = s.board.jumps
          .filter((j) => jumpKind(j) === 'ladder' && j.from > targetPos)
          .sort((a, b) => a.from - b.from)[0];
        if (!foot) return false;
        intents.placements.push([{ player: target, tile: foot.from }]);
        return true;
      }
      case 'swap': {
        if (target === caster) return false;
        const casterPos = getPlayer(s, caster).position;
        intents.placements.push([
          { player: caster, tile: targetPos },
          { player: target, tile: casterPos },
        ]);
        return true;
      }
      case 'addEffect':
        intents.adds.push({ owner: target, template: op.template });
        return true;
      case 'conditional':
        intents.adds.push({
          owner: target,
          template: {
            params: { hook: 'afterMove', cause: op.trigger.cause, condition: op.trigger.condition, amount: op.amount },
            lifetime: op.lifetime,
          },
        });
        return true;
      case 'removeEffects': {
        const matching = s.effects
          .filter((e) => e.owner === target)
          .filter((e) => !op.filter.createdByOthers || e.sourcePlayer !== target)
          .filter((e) => !op.filter.hook || e.params.hook === op.filter.hook)
          .sort((a, b) => a.seq - b.seq);
        const n = op.count === 'all' ? matching.length : op.count;
        intents.removals.push(...matching.slice(0, n).map((e) => e.id));
        return true;
      }
      case 'boardEdit':
        intents.edits.push(op);
        return true;
      case 'gamble': {
        const chosen = op.outcomes[pickWeighted(s.rng.misc, op.outcomes.map((o) => o.weight))]!;
        return chosen.ops.every(visit);
      }
    }
  };
  return card.effects.every(visit) ? intents : null;
}

/**
 * Resolve one simultaneous group (spec §5.4) and return the players whose
 * position changed (they are settled next).
 */
export function resolveGroup(s: MatchState, ev: GameEvent[], group: PendingCard[]): Mover[] {
  const snapshot = new Map(s.players.map((p) => [p.id, p.position] as const));
  const outcomes: CardOutcome[] = [];

  for (const pc of group) {
    const card = cardById(s.config.cards, pc.cardId);
    const caster = getPlayer(s, pc.caster);
    const target =
      pc.target !== null && isValidTarget(s.players, caster, card.target, pc.target)
        ? pc.target
        : selectTarget(s.players, caster, card.target, s.rng.misc);
    if (target === null) {
      outcomes.push({ pc, card, target: null, result: 'fizzled', reason: 'no-target', intents: null });
      continue;
    }
    if (card.type === 'attack' && target !== pc.caster && useAttackShield(s, ev, target)) {
      outcomes.push({ pc, card, target, result: 'blocked', intents: null });
      continue;
    }
    const intents = collectIntents(s, card, pc.caster, target);
    if (!intents) {
      outcomes.push({ pc, card, target, result: 'fizzled', reason: 'no-placement', intents: null });
      continue;
    }
    // Board edits apply immediately in caster seat order; they only fire on landing (D9).
    let editFailed = false;
    for (const op of intents.edits) {
      const editId = nextId(s, 'x');
      const plan = planBoardEdit(s.board, op, getPlayer(s, target).position, editId);
      if (!plan) {
        editFailed = true;
        continue;
      }
      applyPlannedEdit(s.board, plan);
      const edit: BoardEdit = {
        id: editId,
        added: plan.added,
        removed: plan.removed,
        lifetime: op.lifetime,
        createdRound: s.round,
        sourceCard: card.id,
        sourcePlayer: pc.caster,
      };
      s.boardEdits.push(edit);
      ev.push(pub({ type: 'BoardEdited', edit: clonePlain(edit) }));
    }
    if (editFailed && intents.edits.length === card.effects.length) {
      outcomes.push({ pc, card, target, result: 'fizzled', reason: 'no-placement', intents: null });
      continue;
    }
    outcomes.push({ pc, card, target, result: 'hit', intents });
  }

  // Clash: absolute placements touching the same player all fizzle (D11).
  const touches = new Map<PlayerId, number>();
  for (const o of outcomes) for (const pl of o.intents?.placements ?? []) for (const t of pl) touches.set(t.player, (touches.get(t.player) ?? 0) + 1);
  const clashed = outcomes.filter((o) => o.intents?.placements.some((pl) => pl.some((t) => touches.get(t.player)! > 1)));
  if (clashed.length > 0) {
    const players = new Set(clashed.flatMap((o) => o.intents!.placements.flat().map((t) => t.player)));
    ev.push(pub({ type: 'Clash', cardIds: clashed.map((o) => o.card.id), casters: clashed.map((o) => o.pc.caster), players: seatOrder(s, players) }));
    for (const o of clashed) {
      o.result = 'fizzled';
      o.reason = 'clash';
      o.intents!.placements = [];
    }
  }

  for (const o of outcomes) {
    ev.push(
      pub({
        type: 'CardResolved',
        caster: o.pc.caster,
        cardId: o.card.id,
        target: o.target,
        result: o.result,
        ...(o.reason ? { reason: o.reason } : {}),
      }),
    );
  }

  // Positions: surviving placement first, then summed relative moves, with bounce.
  const placed = new Map<PlayerId, number>();
  const deltas = new Map<PlayerId, number>();
  for (const o of outcomes) {
    for (const pl of o.intents?.placements ?? []) for (const t of pl) placed.set(t.player, t.tile);
    for (const d of o.intents?.deltas ?? []) deltas.set(d.player, (deltas.get(d.player) ?? 0) + d.amount);
  }
  const movers: Mover[] = [];
  for (const p of s.players) {
    const start = snapshot.get(p.id)!;
    const base = placed.get(p.id) ?? start;
    const raw = base + (deltas.get(p.id) ?? 0);
    const to = bounce(raw, s.board.size);
    const bounced = raw > s.board.size;
    if (to !== start || bounced) {
      movePlayer(s, ev, p.id, to, 'card', bounced);
      movers.push({ player: p.id, cause: 'card' });
    }
  }

  // Effects: removals only see effects that existed before this group's adds.
  for (const o of outcomes) for (const id of o.intents?.removals ?? []) removeEffect(s, ev, id, 'card');
  for (const o of outcomes) {
    for (const a of o.intents?.adds ?? []) addEffect(s, ev, a.owner, a.template, o.card.id, o.pc.caster);
  }
  return movers;
}
```

```ts
function offerFor(s: MatchState, player: PlayerId): Offer | InputError {
  if (s.phase.kind !== 'mysterySelect') return inputError('WRONG_PHASE', 'not in Mystery selection');
  const offer = s.phase.offers[player];
  if (!offer) return inputError('NOT_AWAITED', `${player} has no Mystery encounter`);
  if (offer.picked !== null) return inputError('ALREADY_PICKED', `${player} already picked`);
  return offer;
}

function isSlot(slot: number): slot is 0 | 1 | 2 {
  return slot === 0 || slot === 1 || slot === 2;

export function rerollInput(s: MatchState, ev: GameEvent[], player: PlayerId, slot: number): InputError | null {
  const offer = offerFor(s, player);
  if ('code' in offer) return offer;
  if (!isSlot(slot)) return inputError('INVALID_SLOT', `slot must be 0, 1 or 2, got ${slot}`);
  if (offer.rerollsUsed >= s.config.mystery.maxRerolls) return inputError('REROLL_LIMIT', 'no rerolls left');
  if (offer.rerolled[slot]) return inputError('SLOT_ALREADY_REROLLED', `slot ${slot} was already rerolled`);
  const from = offer.cards[slot];
  const to = drawCard(s.config.cards, offer.rarity, s.config.mystery.typeWeights, s.rng.cards[getPlayer(s, player).seat]!, from);
  offer.cards[slot] = to;
  offer.rerolled[slot] = true;
  offer.rerollsUsed += 1;
  ev.push(priv(player, { type: 'CardRerolled', player, slot, from, to }));
  return null;
}

export function pickCardInput(s: MatchState, ev: GameEvent[], player: PlayerId, slot: number): InputError | null {
  const offer = offerFor(s, player);
  if ('code' in offer) return offer;
  if (!isSlot(slot)) return inputError('INVALID_SLOT', `slot must be 0, 1 or 2, got ${slot}`);
  offer.picked = slot;
  return null;
}

/** Mystery window expiry: a random displayed card for everyone who has not picked. */
export function mysteryTimeout(s: MatchState): void {
  const phase = s.phase as SelectPhase;
  for (const offer of Object.values(phase.offers)) {
    if (offer.picked === null) {
      offer.picked = nextInt(s.rng.cards[getPlayer(s, offer.player).seat]!, 3);
      offer.autoPicked = true;
    }
  }
}

export function mysteryAwaited(phase: SelectPhase): PlayerId[] {
  return Object.values(phase.offers).filter((o) => o.picked === null).map((o) => o.player);

/**
 * All picks are in: reveal them together, lock hidden targets in seat order
 * and resolve the groups (spec §5.2 step 6, D21).
 */
export function beginResolution(s: MatchState, ev: GameEvent[]): void {
  const phase = s.phase as SelectPhase;
  const pending: PendingCard[] = [];
  for (const p of s.players) {
    const offer = phase.offers[p.id];
    if (!offer) continue;
    const cardId = offer.cards[offer.picked!]!;
    const card = cardById(s.config.cards, cardId);
    pending.push({ caster: p.id, cardId, target: selectTarget(s.players, p, card.target, s.rng.misc) });
    ev.push(pub({ type: 'CardSelected', player: p.id, cardId, cardType: card.type, rarity: card.rarity, auto: offer.autoPicked }));
  }
  s.resolution = groupPendingCards(s.config.cards, pending);
  continueResolution(s, ev);
}

/** Resolve groups until one needs a settle, or end the round when none remain. */
export function continueResolution(s: MatchState, ev: GameEvent[]): void {
  while (s.resolution && s.resolution.length > 0) {
    const group = s.resolution.shift()!;
    const movers = resolveGroup(s, ev, group);
    if (movers.length > 0) {
      s.phase = { kind: 'settle', ctx: { movers, wave: 0, challenges: [] }, after: 'resolveGroups' };
      return;
    }
  }
  s.resolution = null;
  endRound(s, ev);
}
```

```ts
import { challengePickInput, closePickRound } from './challenge';
import { bonusChoiceInput, diceComplete, diceTimeout, finishDicePhase, inputError, rollInput } from './dice';
import { assertInvariants } from './invariants';
import { beginResolution, continueResolution, mysteryAwaited, mysteryTimeout, pickCardInput, rerollInput, startMysteryOrEndRound } from './mystery';
import { runSettle } from './settle';
import type { GameEvent, Input, InputError, MatchState, StepResult } from './types';
import { clonePlain } from './util';

/** Apply one input. Pure from the outside: the given state is never mutated (spec §3.2). */
export function step(state: MatchState, input: Input): StepResult {
  if (state.phase.kind === 'finished') {
    return { ok: false, error: inputError('MATCH_FINISHED', 'the match is over') };
  }
  // config is never mutated, so it is shared rather than cloned (it holds the whole card list).
  const { config, ...rest } = state;
  const s: MatchState = { ...clonePlain(rest), config };
  const ev: GameEvent[] = [];
  const error = dispatch(s, ev, input);
  if (error) return { ok: false, error };
  advance(s, ev);
  if (s.config.checkInvariants) assertInvariants(s);
  return { ok: true, state: s, events: ev };
}

function dispatch(s: MatchState, ev: GameEvent[], input: Input): InputError | null {
  if (input.type !== 'timeout' && !s.players.some((p) => p.id === input.player)) {
    return inputError('UNKNOWN_PLAYER', `unknown player ${input.player}`);
  }
  switch (input.type) {
    case 'roll':
      return rollInput(s, ev, input.player);
    case 'bonusChoice':
      return bonusChoiceInput(s, ev, input.player, input.rollAgain);
    case 'challengePick':
      return challengePickInput(s, ev, input.player, input.challengeId, input.choice);
    case 'reroll':
      return rerollInput(s, ev, input.player, input.slot);
    case 'pickCard':
      return pickCardInput(s, ev, input.player, input.slot);
    case 'timeout':
      return timeout(s, ev, input.windowId);
  }
}

function timeout(s: MatchState, ev: GameEvent[], windowId: number): InputError | null {
  if (windowId !== s.windowId) return inputError('STALE_TIMEOUT', `window ${windowId} is not the current window ${s.windowId}`);
  switch (s.phase.kind) {
    case 'dice':
      diceTimeout(s, ev);
      return null;
    case 'settle':
      closePickRound(s, ev);
      return null;
    case 'mysterySelect':
      mysteryTimeout(s);
      return null;
    case 'finished':
      return inputError('MATCH_FINISHED', 'the match is over');
  }
}

/** Run the state machine forward until it needs player input or the match ends. */
export function advance(s: MatchState, ev: GameEvent[]): void {
  for (;;) {
    const phase = s.phase;
    switch (phase.kind) {
      case 'dice':
        if (!diceComplete(phase)) return;
        finishDicePhase(s, ev);
        break;
      case 'settle':
        if (runSettle(s, ev) === 'waiting') return;
        if (phase.after === 'mysteryDetect') startMysteryOrEndRound(s, ev);
        else continueResolution(s, ev);
        break;
      case 'mysterySelect':
        if (mysteryAwaited(phase).length > 0) return;
        beginResolution(s, ev);
        break;
      case 'finished':
        return;
    }
  }
}
```

```ts
        }),

      publicPhase = { kind: 'mysterySelect', picked };
      myOffer = phase.offers[me] ? clonePlain(phase.offers[me]) : null;
      break;

    case 'finished':
      publicPhase = clonePlain(phase);
      break;

    board: clonePlain(s.board),
    players: clonePlain(s.players),
    effects: clonePlain(s.effects),
    boardEdits: clonePlain(s.boardEdits),
    phase: publicPhase,

    myPicks,
    awaiting: awaiting(s),
  };
```

```ts
import { awaiting, createMatch, step, type GameEvent, type Input, type MatchState } from '../../src/index';

/** A legal input chosen by `choice` (any non-negative integer), or a timeout. */
export function chooseInput(s: MatchState, choice: number): Input {
  const aw = awaiting(s);
  const slot = choice % (aw.players.length + 1);
  if (slot === aw.players.length) return { type: 'timeout', windowId: aw.windowId };
  const player = aw.players[slot]!;
  const phase = s.phase;
  const bit = Math.floor(choice / 7);
  switch (phase.kind) {
    case 'dice':
      return phase.seqs[player]!.status === 'ready'
        ? { type: 'roll', player }
        : { type: 'bonusChoice', player, rollAgain: bit % 2 === 0 };
    case 'settle': {
      const ch = phase.ctx.challenges.find((c) => c.winner === null && c.contesting.includes(player) && c.picks[player] === undefined)!;
      const options = ch.kind === 'rps' ? (['rock', 'paper', 'scissors'] as const) : (['A', 'B'] as const);
      return { type: 'challengePick', player, challengeId: ch.id, choice: options[bit % options.length]! };
    }
    case 'mysterySelect': {
      const offer = phase.offers[player]!;
      const freeSlot = [0, 1, 2].find((i) => !offer.rerolled[i]);
      if (bit % 4 === 3 && offer.rerollsUsed < s.config.mystery.maxRerolls && freeSlot !== undefined) {
        return { type: 'reroll', player, slot: freeSlot };
      }
      return { type: 'pickCard', player, slot: bit % 3 };
    }
    case 'finished':
      throw new Error('match is finished');
  }
}

export interface RandomRun {
  state: MatchState;
  inputs: Input[];
  events: GameEvent[];
}

/** Play a whole match with choices drawn cyclically from `choices`. Throws on any rejected input. */
export function playRandom(seed: string, players: number, choices: number[], maxSteps = 20_000): RandomRun {
  const seats = Array.from({ length: players }, (_, i) => ({ id: `p${i + 1}` }));
  let s = createMatch({ seed }, seats);
  const inputs: Input[] = [];
  const events: GameEvent[] = [];
  for (let i = 0; s.phase.kind !== 'finished'; i++) {
    if (i >= maxSteps) throw new Error(`no winner after ${maxSteps} steps`);
    const input = chooseInput(s, choices[i % choices.length]!);
    const r = step(s, input);
    if (!r.ok) throw new Error(`rejected ${JSON.stringify(input)}: ${r.error.code}`);
    s = r.state;
    inputs.push(input);
    events.push(...r.events);
  }
  return { state: s, inputs, events };
}
```

```ts
import {
  STARTER_CARDS,
  cardById,
  createStream,
  nextInt,
  type CardDef,
  type ChallengeChoice,
  type EffectOp,
  type Input,
  type PlayerSeat,
  type PlayerView,
  type RngStream,
} from '@laddorious/core';

/** A bot sees only its own PlayerView (spec §8.1). 'idle' = do nothing this window. */
export interface Bot {
  decide(view: PlayerView): Input | 'idle';
}

const RPS: ChallengeChoice[] = ['rock', 'paper', 'scissors'];
const MINORITY: ChallengeChoice[] = ['A', 'B'];

function pendingChallenge(view: PlayerView) {
  if (view.phase.kind !== 'settle') return undefined;
  return view.phase.challenges.find(
    (c) => c.winner === null && c.contesting.includes(view.me) && view.myPicks[c.id] === undefined,
  );
}

function challengeInput(view: PlayerView, rng: RngStream): Input | 'idle' {
  const ch = pendingChallenge(view);
  if (!ch) return 'idle';
  const options = ch.kind === 'rps' ? RPS : MINORITY;
  return { type: 'challengePick', player: view.me, challengeId: ch.id, choice: options[nextInt(rng, options.length)]! };
}

/** Uniformly random legal actions; idles for a whole window with probability afkPercent%. */
export class RandomBot implements Bot {
  private idleWindow = -1;
  private decidedWindow = -1;

  constructor(
    private readonly rng: RngStream,
    private readonly afkPercent = 0,
  ) {}

  decide(view: PlayerView): Input | 'idle' {
    const windowId = view.awaiting.windowId;
    if (windowId !== this.decidedWindow) {
      this.decidedWindow = windowId;
      if (this.afkPercent > 0 && nextInt(this.rng, 100) < this.afkPercent) this.idleWindow = windowId;
    }
    if (this.idleWindow === windowId) return 'idle';
    const me = view.me;
    const phase = view.phase;
    if (phase.kind === 'dice') {
      const seq = phase.seqs[me];
      if (seq?.status === 'ready') return { type: 'roll', player: me };
      if (seq?.status === 'bonusPending') return { type: 'bonusChoice', player: me, rollAgain: nextInt(this.rng, 2) === 0 };
      return 'idle';
    }
    if (phase.kind === 'settle') return challengeInput(view, this.rng);
    if (phase.kind === 'mysterySelect' && view.myOffer && view.myOffer.picked === null) {
      const offer = view.myOffer;
      const free = [0, 1, 2].filter((i) => !offer.rerolled[i]);
      if (offer.rerollsUsed < 2 && free.length > 0 && nextInt(this.rng, 10) < 3) {
        return { type: 'reroll', player: me, slot: free[nextInt(this.rng, free.length)]! };
      }
      return { type: 'pickCard', player: me, slot: nextInt(this.rng, 3) };
    }
    return 'idle';
  }
}

/** Rough tile value of a card for the caster (spec §8.1 heuristic). */
export function scoreCard(card: CardDef, view: PlayerView): number {
  const me = view.players.find((p) => p.id === view.me)!;
  const selfTarget = card.target.condition === 'self';
  const value = (op: EffectOp): number => {
    switch (op.op) {
      case 'moveRelative':
        return selfTarget ? op.amount : -op.amount * 0.8;
      case 'moveTo':
        return 6;
      case 'swap': {
        const ahead = view.players.filter((p) => p.position > me.position).map((p) => p.position - me.position);
        return ahead.length > 0 ? Math.max(...ahead) : 0;
      }
      case 'addEffect': {
        const p = op.template.params;
        if (p.hook === 'diceFace') return 3;
        if (p.hook === 'diceTotal') {
          if (p.op === 'multiply') return 4 * (p.value - 1);
          if (p.op === 'replace') return p.value - 4;
          return selfTarget ? p.value : -p.value;
        }
        return 2;
      }
      case 'removeEffects':
        return view.effects.some((e) => e.owner === view.me && e.sourcePlayer !== view.me) ? 3 : 0;
      case 'boardEdit':
        return 2;
      case 'gamble': {
        const total = op.outcomes.reduce((a, o) => a + o.weight, 0);
        return op.outcomes.reduce((a, o) => a + (o.weight / total) * o.ops.reduce((b, x) => b + value(x), 0), 0);
      }
      case 'conditional':
        return 1;
    }
  };
  return card.effects.reduce((a, op) => a + value(op), 0);
}

/** Avoids overshooting with bonus rolls, rerolls weak cards, picks the best-scoring card. */
export class HeuristicBot implements Bot {
  constructor(
    private readonly rng: RngStream,
    private readonly cards: readonly CardDef[],
    private readonly rerollBelow = 1,
  ) {}

  decide(view: PlayerView): Input | 'idle' {
    const me = view.me;
    const phase = view.phase;
    if (phase.kind === 'dice') {
      const seq = phase.seqs[me];
      if (seq?.status === 'ready') return { type: 'roll', player: me };
      if (seq?.status === 'bonusPending') {
        const pos = view.players.find((p) => p.id === me)!.position;
        const total = seq.faces.reduce((a, b) => a + b, 0);
        return { type: 'bonusChoice', player: me, rollAgain: pos + total + 6 <= view.board.size };
      }
      return 'idle';
    }
    if (phase.kind === 'settle') return challengeInput(view, this.rng);
    if (phase.kind === 'mysterySelect' && view.myOffer && view.myOffer.picked === null) {
      const offer = view.myOffer;
      const scores = offer.cards.map((id) => scoreCard(cardById(this.cards, id), view));
      const worst = scores.indexOf(Math.min(...scores));
      if (scores[worst]! < this.rerollBelow && offer.rerollsUsed < 2 && !offer.rerolled[worst]) {
        return { type: 'reroll', player: me, slot: worst };
      }
      return { type: 'pickCard', player: me, slot: scores.indexOf(Math.max(...scores)) };
    }
    return 'idle';
  }
}

export type PolicyName = 'random' | 'heuristic';

/** One bot per seat, each with its own seeded stream so batches are reproducible. */
export function makeBots(seats: PlayerSeat[], policy: PolicyName, seed: string, afkPercent: number): Record<string, Bot> {
  const bots: Record<string, Bot> = {};
  for (const seat of seats) {
    const rng = createStream(`${seed}|bot|${seat.id}`);
    bots[seat.id] = policy === 'random' ? new RandomBot(rng, afkPercent) : new HeuristicBot(rng, STARTER_CARDS);
  }
  return bots;
}
```

```ts
import {
  awaiting,
  createMatch,
  hashState,
  step,
  viewFor,
  type Board,
  type GameEvent,
  type Input,
  type MatchConfigInput,
  type MatchState,
  type PlayerId,
  type PlayerSeat,
} from '@laddorious/core';
import type { Bot } from './bots';

/** Everything needed to reproduce a match exactly (spec §3.5). */
export interface MatchLog {
  config: MatchConfigInput;
  seats: PlayerSeat[];
  inputs: Input[];
  finalHash: string;
}

export interface MatchRun {
  state: MatchState;
  events: GameEvent[];
  log: MatchLog;
  /** Unique leader at the end of each round (null on a tie), index 0 = round 1. */
  roundLeaders: Array<PlayerId | null>;
}

function leaderOf(s: MatchState): PlayerId | null {
  const max = Math.max(...s.players.map((p) => p.position));
  const top = s.players.filter((p) => p.position === max);
  return top.length === 1 ? top[0]!.id : null;
}

export interface RunOptions {
  maxSteps?: number;
  /** A board already generated from config.seed — saves generating it twice. Replays regenerate it from the seed. */
  board?: Board;
}

/**
 * Drive one match with bots (spec §8.2): ask each awaited bot for an input;
 * when every awaited bot idles, the window times out. No real time passes.
 */
export function runMatch(config: MatchConfigInput, seats: PlayerSeat[], bots: Record<PlayerId, Bot>, opts: RunOptions = {}): MatchRun {
  const maxSteps = opts.maxSteps ?? 100_000;
  let s = createMatch(config, seats, opts.board);
  const events: GameEvent[] = [];
  const inputs: Input[] = [];
  const roundLeaders: Array<PlayerId | null> = [];

  const apply = (input: Input) => {
    const r = step(s, input);
    if (!r.ok) throw new Error(`illegal input ${JSON.stringify(input)}: ${r.error.code} ${r.error.message}`);
    s = r.state;
    inputs.push(input);
    events.push(...r.events);
    if (r.events.some((e) => e.type === 'RoundEnded')) roundLeaders.push(leaderOf(s));
  };

  for (let n = 0; s.phase.kind !== 'finished'; n++) {
    if (n >= maxSteps) throw new Error(`match did not finish within ${maxSteps} steps`);
    const aw = awaiting(s);
    let acted = false;
    for (const id of aw.players) {
      const input = bots[id]!.decide(viewFor(s, id));
      if (input === 'idle') continue;
      apply(input);
      acted = true;
      break;
    }
    if (!acted) apply({ type: 'timeout', windowId: aw.windowId });
  }

  return { state: s, events, log: { config, seats, inputs, finalHash: hashState(s) }, roundLeaders };
}

/** Re-run a log and report whether the final state hash matches (spec §8.3). */
export function replayLog(log: MatchLog): { ok: boolean; hash: string; state: MatchState } {
  let s = createMatch(log.config, log.seats);
  for (const input of log.inputs) {
    const r = step(s, input);
    if (!r.ok) throw new Error(`replay failed at ${JSON.stringify(input)}: ${r.error.code}`);
    s = r.state;
  }
  const hash = hashState(s);
  return { ok: hash === log.finalHash, hash, state: s };
}
```

```ts
  CARD_TYPES,
  RARITIES,
  type CardType,
  type GameEvent,
  type GenerationReport,
  type PlayerId,
  type Rarity,
  type RejectionReason,

/** Seconds per activity — estimates until real playtests (spec §8.4). */
export interface TimeModel {
  diceSec: number;
  bonusSec: number;
  moveSec: number;
  challengeWindowSec: number;
  mysterySelectSec: number;
  revealSec: number;
  perCardSec: number;
  roundOverheadSec: number;
}

export const DEFAULT_TIME_MODEL: TimeModel = {
  diceSec: 6,
  bonusSec: 2,
  moveSec: 2,
  challengeWindowSec: 6,
  mysterySelectSec: 10,
  revealSec: 1,
  perCardSec: 1.5,
  roundOverheadSec: 1,
};

export interface MatchMetrics {
  rounds: number;
  winnerSeat: number;
  estimatedSeconds: number;
  challenges: number;
  challengeWindows: number;
  safetyCaps: number;
  encounters: number;
  picksByType: Record<CardType, number>;
  picksByRarity: Record<Rarity, number>;
  rerolls: number;
  results: { hit: number; blocked: number; fizzled: number };
  clashes: number;
  leadChanges: number;
  /** The winner was not the unique leader at the end of round 10. */
  comeback: boolean;
}

export function matchMetrics(run: MatchRun, tm: TimeModel = DEFAULT_TIME_MODEL): MatchMetrics {
  const { state, events } = run;
  if (state.phase.kind !== 'finished') throw new Error('match not finished');
  const winner: PlayerId = state.phase.winner;
  const count = (type: GameEvent['type']) => events.filter((e) => e.type === type).length;

  const roundsWithBonus = new Set<number>();
  const roundsWithEncounter = new Set<number>();
  let round = 1;
  for (const e of events) {
    if (e.type === 'RoundStarted') round = e.round;
    if (e.type === 'BonusChosen' && e.rollAgain) roundsWithBonus.add(round);
    if (e.type === 'CardSelected') roundsWithEncounter.add(round);
  }

  const picksByType = Object.fromEntries(CARD_TYPES.map((t) => [t, 0])) as Record<CardType, number>;
  const picksByRarity = Object.fromEntries(RARITIES.map((r) => [r, 0])) as Record<Rarity, number>;
  const results = { hit: 0, blocked: 0, fizzled: 0 };
  for (const e of events) {
    if (e.type === 'CardSelected') {
      picksByType[e.cardType] += 1;
      picksByRarity[e.rarity] += 1;
    }
    if (e.type === 'CardResolved') results[e.result] += 1;
  }

  const challengeWindows = events.filter((e) => e.type === 'WindowOpened' && e.window === 'challenge').length;
  const cardsResolved = count('CardResolved');
  const estimatedSeconds =
    state.round * (tm.roundOverheadSec + tm.diceSec + tm.moveSec) +
    roundsWithBonus.size * tm.bonusSec +
    challengeWindows * tm.challengeWindowSec +
    roundsWithEncounter.size * (tm.mysterySelectSec + tm.revealSec) +
    cardsResolved * tm.perCardSec;

  let leadChanges = 0;
  let last: PlayerId | null = null;
  for (const leader of run.roundLeaders) {
    if (leader !== null && last !== null && leader !== last) leadChanges++;
    if (leader !== null) last = leader;
  }

  return {
    rounds: state.round,
    winnerSeat: state.players.find((p) => p.id === winner)!.seat,
    estimatedSeconds,
    challenges: count('ChallengeStarted'),
    challengeWindows,
    safetyCaps: count('SafetyCapApplied'),
    encounters: count('MysteryOffered'),
    picksByType,
    picksByRarity,
    rerolls: count('CardRerolled'),
    results,
    clashes: count('Clash'),
    leadChanges,
    comeback: run.roundLeaders.length >= 10 && run.roundLeaders[9] !== winner,
  };
}

export function quantile(values: readonly number[], q: number): number {
  if (values.length === 0) return NaN;
  const sorted = [...values].sort((a, b) => a - b);
  const idx = Math.min(sorted.length - 1, Math.max(0, Math.round(q * (sorted.length - 1))));
  return sorted[idx]!;
}

const mean = (xs: readonly number[]) => (xs.length === 0 ? NaN : xs.reduce((a, b) => a + b, 0) / xs.length);

export interface GeneratorSummary {
  boards: number;
  attemptsMean: number;
  attemptsMax: number;
  rejections: Partial<Record<RejectionReason, number>>;
}

/** Board-generator health across a batch (spec §8.4). */
export function summarizeGeneration(reports: readonly GenerationReport[]): GeneratorSummary {
  const rejections: Partial<Record<RejectionReason, number>> = {};
  for (const r of reports) {
    for (const [reason, n] of Object.entries(r.rejections) as Array<[RejectionReason, number]>) rejections[reason] = (rejections[reason] ?? 0) + n;
  }
  return {
    boards: reports.length,
    attemptsMean: mean(reports.map((r) => r.attempts)),
    attemptsMax: reports.reduce((m, r) => Math.max(m, r.attempts), 0),
    rejections,
  };
}

export interface BatchReport {
  matches: number;
  rounds: { p10: number; median: number; p90: number };
  minutes: { p10: number; median: number; p90: number };
  perMatch: {
    challenges: number;
    challengeWindows: number;
    safetyCaps: number;
    encounters: number;
    rerolls: number;
    clashes: number;
    leadChanges: number;
  };
  encountersPerRound: number;
  picksByType: Record<CardType, number>;
  picksByRarity: Record<Rarity, number>;
  results: { hit: number; blocked: number; fizzled: number };
  winRateBySeat: number[];
  comebackRate: number;
  generator: GeneratorSummary;
}

export function aggregate(all: MatchMetrics[], seats: number, generation: readonly GenerationReport[] = []): BatchReport {
  const sum = <K extends keyof MatchMetrics>(k: K) => all.map((m) => m[k] as number);
  const minutes = all.map((m) => m.estimatedSeconds / 60);
  const picksByType = Object.fromEntries(CARD_TYPES.map((t) => [t, all.reduce((a, m) => a + m.picksByType[t], 0)])) as Record<CardType, number>;
  const picksByRarity = Object.fromEntries(RARITIES.map((r) => [r, all.reduce((a, m) => a + m.picksByRarity[r], 0)])) as Record<Rarity, number>;
  const totalRounds = all.reduce((a, m) => a + m.rounds, 0);
  return {
    matches: all.length,
    rounds: { p10: quantile(sum('rounds'), 0.1), median: quantile(sum('rounds'), 0.5), p90: quantile(sum('rounds'), 0.9) },
    minutes: { p10: quantile(minutes, 0.1), median: quantile(minutes, 0.5), p90: quantile(minutes, 0.9) },
    perMatch: {
      challenges: mean(sum('challenges')),
      challengeWindows: mean(sum('challengeWindows')),
      safetyCaps: mean(sum('safetyCaps')),
      encounters: mean(sum('encounters')),
      rerolls: mean(sum('rerolls')),
      clashes: mean(sum('clashes')),
      leadChanges: mean(sum('leadChanges')),
    },
    encountersPerRound: all.reduce((a, m) => a + m.encounters, 0) / totalRounds,
    picksByType,
    picksByRarity,
    results: {
      hit: all.reduce((a, m) => a + m.results.hit, 0),
      blocked: all.reduce((a, m) => a + m.results.blocked, 0),
      fizzled: all.reduce((a, m) => a + m.results.fizzled, 0),
    },
    winRateBySeat: Array.from({ length: seats }, (_, seat) => all.filter((m) => m.winnerSeat === seat).length / all.length),
    comebackRate: all.filter((m) => m.comeback).length / all.length,
    generator: summarizeGeneration(generation),
  };
}

export function formatReport(r: BatchReport): string {
  const f = (n: number, d = 2) => n.toFixed(d);
  const lines = [
    `Matches:              ${r.matches}`,
    `Rounds (p10/med/p90): ${r.rounds.p10} / ${r.rounds.median} / ${r.rounds.p90}`,
    `Minutes est.:         ${f(r.minutes.p10, 1)} / ${f(r.minutes.median, 1)} / ${f(r.minutes.p90, 1)}`,
    `Challenges/match:     ${f(r.perMatch.challenges)}  (windows ${f(r.perMatch.challengeWindows)}, safety caps ${f(r.perMatch.safetyCaps, 3)})`,
    `Encounters/round:     ${f(r.encountersPerRound)}  (rerolls/match ${f(r.perMatch.rerolls)})`,
    `Picks by type:        ${Object.entries(r.picksByType).map(([k, v]) => `${k} ${v}`).join(', ')}`,
    `Picks by rarity:      ${Object.entries(r.picksByRarity).map(([k, v]) => `${k} ${v}`).join(', ')}`,
    `Card results:         hit ${r.results.hit}, blocked ${r.results.blocked}, fizzled ${r.results.fizzled}; clashes/match ${f(r.perMatch.clashes, 3)}`,
    `Win rate by seat:     ${r.winRateBySeat.map((w) => `${f(w * 100, 1)}%`).join(' / ')}`,
    `Lead changes/match:   ${f(r.perMatch.leadChanges)}   Comeback rate: ${f(r.comebackRate * 100, 1)}%`,
    `Board generation:     ${r.generator.boards} boards, attempts mean ${f(r.generator.attemptsMean)} / max ${r.generator.attemptsMax}; rejections ${JSON.stringify(r.generator.rejections)}`,
  ];
  return lines.join('\n');
}
```

```ts
import { generateBoard, resolveConfig, type GenerationReport, type MatchConfigInput, type PlayerSeat } from '@laddorious/core';
import { makeBots, type PolicyName } from './bots';
import { aggregate, matchMetrics, type BatchReport, type MatchMetrics } from './metrics';
import { runMatch, type MatchLog } from './runner';

export interface BatchOptions {
  matches: number;
  players: number;
  policy: PolicyName;
  baseSeed: string;
  afkPercent: number;
  /** Extra config applied to every match (seed is derived per match). */
  config?: Omit<MatchConfigInput, 'seed'>;
}

export interface BatchResult {
  report: BatchReport;
  metrics: MatchMetrics[];
  generation: GenerationReport[];
  firstLog: MatchLog | null;
}

/** Run a reproducible batch: match i uses seed `${baseSeed}-${i}` (spec §8.2). */
export function runBatch(opts: BatchOptions): BatchResult {
  const seats: PlayerSeat[] = Array.from({ length: opts.players }, (_, i) => ({ id: `p${i + 1}` }));
  const metrics: MatchMetrics[] = [];
  const generation: GenerationReport[] = [];
  let firstLog: MatchLog | null = null;
  for (let i = 0; i < opts.matches; i++) {
    const seed = `${opts.baseSeed}-${i}`;
    const config: MatchConfigInput = { checkInvariants: false, ...opts.config, seed };
    // Generate the board here (the same board createMatch would build) so its report is kept.
    const { board, report } = generateBoard(seed, resolveConfig(config).board);
    generation.push(report);
    const run = runMatch(config, seats, makeBots(seats, opts.policy, seed, opts.afkPercent), { board });
    if (i === 0) firstLog = run.log;
    metrics.push(matchMetrics(run));
  }
  return { report: aggregate(metrics, opts.players, generation), metrics, generation, firstLog };
}
```

```ts
import { readFileSync, writeFileSync } from 'node:fs';
import { parseArgs } from 'node:util';
import { DEFAULT_BOARD_CONFIG, generateBoard, renderBoardAscii } from '@laddorious/core';
import { runBatch } from './batch';
import type { PolicyName } from './bots';
import { formatReport } from './metrics';
import { replayLog, type MatchLog } from './runner';

const USAGE = `Usage:
  sim run [--matches 1000] [--players 4] [--policy heuristic|random] [--seed base] [--afk 0] [--out report.json] [--log match0.json]
  sim board --seed X
  sim replay <log.json>`;

export function main(argv: string[]): number {
  const [command, ...rest] = argv;
  switch (command) {
    case 'run': {
      const { values } = parseArgs({
        args: rest,
        options: {
          matches: { type: 'string', default: '1000' },
          players: { type: 'string', default: '4' },
          policy: { type: 'string', default: 'heuristic' },
          seed: { type: 'string', default: 'base' },
          afk: { type: 'string', default: '0' },
          out: { type: 'string' },
          log: { type: 'string' },
        },
      });
      const policy = values.policy as PolicyName;
      if (policy !== 'heuristic' && policy !== 'random') throw new Error(`unknown policy ${values.policy}`);
      const started = Date.now();
      const { report, firstLog } = runBatch({
        matches: Number(values.matches),
        players: Number(values.players),
        policy,
        baseSeed: values.seed!,
        afkPercent: Number(values.afk),
      });
      console.log(formatReport(report));
      console.log(`Elapsed:              ${((Date.now() - started) / 1000).toFixed(1)} s`);
      if (values.out) writeFileSync(values.out, JSON.stringify(report, null, 2));
      if (values.log && firstLog) writeFileSync(values.log, JSON.stringify(firstLog));
      return 0;
    }
    case 'board': {
      const { values } = parseArgs({ args: rest, options: { seed: { type: 'string' } } });
      if (!values.seed) throw new Error('board needs --seed');
      const { board, report } = generateBoard(values.seed, DEFAULT_BOARD_CONFIG);
      console.log(renderBoardAscii(board));
      console.log(`Attempts: ${report.attempts}  Rejections: ${JSON.stringify(report.rejections)}`);
      console.log(
        `Median first finish: 4p ${report.analysis.median4p} rounds, 2p ${report.analysis.median2p} rounds; P(2p > 60 rounds) = ${(report.analysis.tail2p * 100).toFixed(2)}%`,
      );
      return 0;
    }
    case 'replay': {
      const file = rest[0];
      if (!file) throw new Error('replay needs a log file');
      const log = JSON.parse(readFileSync(file, 'utf8')) as MatchLog;
      const result = replayLog(log);
      console.log(result.ok ? `OK ${result.hash}` : `MISMATCH expected ${log.finalHash}, got ${result.hash}`);
      return result.ok ? 0 : 1;
    }
    default:
      console.log(USAGE);
      return command === undefined || command === 'help' ? 0 : 1;
  }
}
```
